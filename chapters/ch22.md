# 第四部分 · 逻辑判断（上）：逻辑论证 · 一、归因论证

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

题干给出一组事实并解释其原因。考的是「原因判断是否站得住」，核心武器是另有他因、因果倒置、否定此因。

## 对比实验归因 · 另有他因　★★★

`K4-1-1`

题干用「实验组 vs 对照组」的差异结果，推出某一原因导致该结果；削弱时指出两组之间还存在**另一个可能影响结果的不同点**。

**识别信号**
- 题干出现完整实验过程：分组、处理、结果、结论或建议
- 问法多为「以下哪项如果为真，最能削弱上述结论」
- 少数问「最能质疑研究人员的解释」，此时抓住「解释」即可，更简单

**解题步骤**
1. 圈出实验组与对照组，确认「分组是按什么分的」
2. 找出结论认定的原因，以及结果指标
3. 在选项中找「另一处两组不同」——必须落在同一实验分组上
4. 若题干有多种分组方式，按最终结论反推正确分组，再找该分组下的他因

**规则 / 公式 / 结论**
- 正确项必须同时满足：讨论原因 + 分组正确
- 「继发关联」型他因：A 与 B 无因果，二者同由 C 导致（A←C→B），也属于另有他因

**易错**
- 未谈原因的选项（只谈结果、只谈现象）
- 未分组的「伪他因」：与实验分组无关的第三方差异
- 「有些」「特例」类选项，正确概率极低
- 实验瑕疵类（样本不足、未全覆盖）：质疑力度很弱，通常不是答案

**例题**
- 某讲师不喜欢运动且很胖，据此认为「不爱运动会导致长胖」。以下哪项最能削弱？
  - 答案：该讲师还有暴饮暴食的习惯——引入饮食这一他因，切断「不运动→胖」的归因（若「一果多因」，说明不能唯一归因于不运动）。
- 题干称地球转速放缓导致强震多发。以下哪项最能削弱？
  - 答案：「继发关联」陷阱：地核轻微变化同时导致转速放缓与强震多发，二者并非因果，而是同因之果。

**关联**：因果倒置（K4-1-2）；四圈支持/三圈质疑（K4-1-8）

## 因果倒置　★★★

`K4-1-2`

把原因与结果互相颠倒：题干认为 A 导致 B，削弱时指出实际是 B 导致 A。

**识别信号**
- 题干是「相对确定」的因果陈述，而非实验分组
- 结论句式：「A 会/能导致 B」「A 是 B 的原因」

**解题步骤**
1. 把题干写成 A→B
2. 在选项中找「B→A」的表述
3. 确认时间或逻辑上的先后能否成立（倒置必须讲得通）

**规则 / 公式 / 结论**
- 质疑力度：否定此因 = 因果倒置 > 另有他因
- 因果倒置一旦成立，直接否定题干的因果方向，力度最强档

**易错**
- 把「相关」当「因果」：只说 A、B 同时出现，不构成倒置
- 倒置方向写反（说成 A→B 的加强）

**例题**
- 题干：经常运动的人更少患病，故运动能减少患病。以下哪项最能削弱？
  - 答案：体质好的人更愿意运动——是「健康→运动」，颠倒题干因果。

**关联**：另有他因（K4-1-1）；否定此因（K4-1-3）

## 否定此因　★★

`K4-1-3`

不探讨结果真正的原因是什么，只直接否定题干认定的那个原因。

**识别信号**
- 题干因果较简单，没有实验分组
- 选项出现「并不是 A 导致的」「A 与此无关」

**解题步骤**
1. 锁定题干认定的原因 A
2. 在选项中找直接否认 A 的表述
3. 与另有他因区分：另有他因引入新原因，否定此因只拆掉旧原因

**规则 / 公式 / 结论**
- 力度与因果倒置同级，强于另有他因

**易错**
- 把「另有他因」误判为否定此因（两者可同时成立，但只有一项在选项里）

**例题**
- 题干：饮用某水导致村民长寿。以下哪项最能削弱？
  - 答案：该村长寿者并无长期饮用该水的记录——直接否定「饮水」这一原因。

**关联**：因果倒置（K4-1-2）

## 排除他因支持　★★

`K4-1-4`

通过排除其他可能影响结果的原因，使题干认定的原因成为唯一可能，从而支持结论。

**识别信号**
- 问法为「最能支持/加强上述结论」
- 题干为因果归因，选项在「排除干扰因素」

**解题步骤**
1. 找出结论认定的原因
2. 在选项中找「其他原因都不成立/都被控制」的表述
3. 确认排除的是「可能影响结果的原因」，而不是无关因素

**规则 / 公式 / 结论**
- 排除他因 = 归因类加强的标准姿势；与「另有他因」互为镜像

**易错**
- 排除的是无关变量（如天气、地点），对结论无影响

**例题**
- 题干：某地居民幸福感高，因当地空气好。以下哪项最能支持？
  - 答案：该地居民收入、就业、治安等与幸福感相关的因素与全国平均水平相当——排除他因。

**关联**：另有他因（K4-1-1）

## 时间对比归因　★★

`K4-1-5`

题干对比「当前」与「以往」的某种变化并归因；削弱时指出当前与过去还有**另一处不同**，用他因削弱。

**识别信号**
- 题干出现「近年来」「与五年前相比」「过去 5 年」等时间对比
- 结论：某变化是由某原因造成的

**解题步骤**
1. 确定「变化的结果」是什么
2. 找出题干归因的原因
3. 在选项中找同一时间段内的「另一处变化」

**规则 / 公式 / 结论**
- 一直存在且没有变化的事实，不会是某种「变化」的原因——变化只能由变化解释
- 注意选项中与题干相同的时间表述（两年前、过去 5 年、1990 年等）

**易错**
- 用恒定因素解释变化（时间错位）

**例题**
- 题干：近五年该市近视率上升，因学生课业负担加重。以下哪项最能削弱？
  - 答案：近五年该市中小学生手机使用时长增加了两倍——同一时间段的另一处变化。

**关联**：一般归因（K4-1-6）

## 一般归因　★

`K4-1-6`

没有明显对比实验、也没有时间对比，只针对某个既成事实归因；本质仍是「某种情况与其他情况的对比」。

**识别信号**
- 题干陈述一个事实并给出解释
- 无实验组、无时间线

**解题步骤**
1. 把「事实」与「默认对照情形」区分开
2. 按另有他因/否定此因/因果倒置三条路逐一验证选项

**规则 / 公式 / 结论**
- 可视为对比实验的弱化版，套路相同

**易错**
- 把一般归因误当对比实验，去找不存在的分组

**例题**
- 题干：某景区游客锐减，因门票涨价。以下哪项最能削弱？
  - 答案：同期该景区周边道路施工，通行时间增加一倍——引入他因。

**关联**：时间对比归因（K4-1-5）

## 直接根本原因（固定题型）　★★

`K4-1-7`

题干由「原观点」与「反对者观点」组成，多问「质疑反对者」；答案是「原观点认为的原因」导致了「反对者认为的原因」。

**识别信号**
- 两个观点对峙
- 问法：质疑反对者/支持原观点

**解题步骤**
1. 标出原观点原因 A、反对者原因 B
2. 找「A 导致 B」的选项，即 A 是 B 的根本原因
3. 确认因果链方向：原观点原因在前

**规则 / 公式 / 结论**
- 该题型可秒杀：正确项几乎固定为「A→B」的搭桥表述

**易错**
- 选择「B→A」的倒置项
- 选择仅重复原观点的选项

**例题**
- 原观点：甲导致丙；反对者：乙才是丙的原因。问质疑反对者。
  - 答案：甲导致了乙——原观点原因导致反对者原因，直接拆掉反对者的独立性。

**关联**：断点搭桥（K4-3-1）

## 构成或补充对比实验（四圈支持 / 三圈质疑）　★★★

`K4-1-8`

选项本身构成一个对比实验：与题干互为实验组/对照组，通过「异因异果」支持，通过「异因同果」或「同因异果」质疑。

**识别信号**
- 题干已有实验，选项再造一组对照
- 选项出现「另一组人中……」

**解题步骤**
1. 画两圈：题干组、选项组
2. 比较「原因是否相同」与「结果是否相同」
3. 异因异果 → 支持（四圈支持）；异因同果、同因异果 → 质疑（三圈质疑）

**规则 / 公式 / 结论**
- 四圈支持：两因不同、两果不同，因果对应成立
- 三圈质疑：因不同而果相同，或因相同而果不同，说明因果不成立

**易错**
- 只看结果不看原因，误把「同果」当支持

**例题**
- 题干：服用 X 的人更少感冒，故 X 能防感冒。选项：服用安慰剂的人感冒率与服药组相同。
  - 答案：同果异因——属三圈质疑，说明 X 并非原因。

**关联**：另有他因（K4-1-1）
