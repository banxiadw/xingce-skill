# 第五部分 · 逻辑判断（下）：逻辑推理 · 五、推出类：翻译推理

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

题干给命题，问能推出什么。四条路：等价推出、正推、逆推、两难。

## 等价推出　★★★

`K5-2-1`

题干译成 A→B 后，选项等于 A→B 或 非 B→非 A 即为正确；以 B、非 A 开头的选项通常先排除。

**识别信号**
- 问法：由此可以推出/不能推出
- 题干只有一个或少数几个命题

**解题步骤**
1. 翻译题干
2. 逐项翻译选项，保留等价形式
3. 多项命题时先不联立，看答案只涉及哪一句

**规则 / 公式 / 结论**
- 等价只有两种写法：原命题、逆否命题（否定前件/肯定后件都不等价）

**易错**
- 「肯前必肯后，否后必否前；否前肯后不必然」记反

**例题**
- 「只有尊重人民意愿，人民才会支持改革」可以推出？
  - 答案：若人民支持改革，则尊重了人民意愿——后推前的逆否。

**关联**：正推与逆推（K5-2-2）

## 正推与逆推　★★

`K5-2-2`

正推：由已知事实沿箭头方向传递；逆推：由目标结果反推所需条件（常考「或」的否一推一）。

**识别信号**
- 题干给「已知某人/某事成立」
- 问「哪项为真可推出 X」

**解题步骤**
1. 正推：把事实代入命题链，逐步得结论
2. 逆推：目标写在箭头后，倒推前件；遇「或」用否一推一

**规则 / 公式 / 结论**
- A→B、B→C 可联立得 A→C；A→B、C→B 不可联立

**易错**
- 把「或」当「且」逆推
- 联立方向搞反

**例题**
- 吴教语文→张不教生物；孙教语文或吴教语文；张不教生物→苏不教物理；吴不教化学或苏教物理。哪项为真可推出孙教语文？
  - 答案：吴老师教化学——逆推链：孙语文→吴非语文→张生物→苏物理→吴化学。

**关联**：等价推出（K5-2-1）

---

## 两难推理　★★

`K5-2-3`

A→B 且 非 A→B，则 B 恒成立；A→B 且 A→非 B，则非 A 恒成立。

**识别信号**
- 题干两条命题前件互补、后件相同（或相反）

**解题步骤**
1. 识别前件是否为 A 与 非 A
2. 确认后件相同 → 后件必真；后件相反 → 前件必假

**规则 / 公式 / 结论**
- 两难的本质是穷尽前件的两种可能

**易错**
- 前件不互补时误用

**例题**
- 如果张生不喜欢旅游，则他对驾车也不感兴趣。据此可推出？
  - 答案：张生喜欢旅游——「非旅游→非驾车」逆否得「驾车→旅游」，两种情形都指向旅游。

**关联**：等价推出（K5-2-1）

## 范畴推理（三段论 / 集合关系）　★★★

`K5-2-4`

按「所有/有些/特指」的关系推理；复杂题用文氏图画集合，先分两边再画圈。

**识别信号**
- 题干多个「所有/有些」
- 问「一定为真/一定为假」

**解题步骤**
1. 先用最大集合（如 B）把整体分为 B / 非 B 两边
2. 把「所有 A 都是 B」画进 B 一侧，「所有 C 都不是 B」画到另一侧
3. 「有些」画成与相关圈相交，注意相交位置不唯一

**规则 / 公式 / 结论**
- 三段论技巧：所有+有些=有些；是+是=是、是+否=否；三个概念各出现两次
- 「有些 A 是 B」推不出「有些 A 不是 B」；未限定条件的概念不能确定位置

**易错**
- 把「有些」画死在某个区域
- 忽略「所有 C 都不是 B」对 C 的强制排除

**例题**
- 所有法学专业学生都获得法律职业资格证；所有获法律职业资格证者都获教师资格证；有些法学专业学生成为公务员；所有逻辑学专业学生都未获教师资格证。以下一定为假？
  - 答案：「有些逻辑学专业学生成为公务员且获得教师资格证」类表述——逻辑学全部无教师资格证，与包含关系冲突。

**关联**：直言命题（K5-1-3）

## 推理方式判断与论证结构相似　★★

`K5-2-5`

演绎（一般→特殊）、归纳（特殊→一般，分完全/不完全）、类比（特殊→特殊）；结构相似题比对「论证骨架」。

**识别信号**
- 问「与上述推理方式相同/最为类似」
- 题干含举例、调查、类推

**解题步骤**
1. 先判定题干是演绎、归纳还是类比
2. 归纳再分完全（穷尽）与不完全（枚举）
3. 结构相似题抽出骨架（如「有的 A 是 B，C 是 A，所以 C 是 B」），逐项套

**规则 / 公式 / 结论**
- 抽样调查推全体 = 不完全归纳；逐一考察全部对象 = 完全归纳
- 常见错误骨架：A→B 且 C 是 B 推出 C 是 A；A→B 且 C 非 A 推出 C 非 B；分割谬误（整体属性推个体）

**易错**
- 把演绎当归纳（有一般原理在前即为演绎）
- 把类比当归纳

**例题**
- 考察 260 名杀人犯外貌后得出「杀人犯具有某共同特征」。以下哪项推理方式相同？
  - 答案：「八月十五云遮月，正月十五雪打灯」——同属不完全归纳（由部分观察推普遍结论）。

**关联**：范畴推理（K5-2-4）
