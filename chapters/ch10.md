# 第一部分 · 图形推理 · 十、特殊载体：汉字、字母、数字、Logo

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

载体特殊但考点不变：先看横竖，再看面、部分数，最后看对称与笔画。

## 汉字：横竖、面、部分、笔画　★★★

`K1-10-1`

汉字题按「先横竖线条 → 再封闭面 → 再部分数 → 最后笔画/对称/偏旁」的顺序看。

**识别信号**
- 一串汉字
- 汉字与图形混排

**解题步骤**
1. 黑体字先数横线、竖线
2. 再看封闭面个数（口、日、田）
3. 仍无规律 → 部分数、笔画数、对称、第一笔、偏旁

**规则 / 公式 / 结论**
- 「采、杯、击、回、岖」类字先横竖；「口、土、目、木、由、丰、日」类先看开闭

**易错**
- 用楷体笔画数去数黑体字

**例题**
- 两行汉字：采、杯、击、回、岖 + 问号；水、中、月、申、晶 + 问号。
  - 答案：先看横竖线条数量，再看面与部分数。
- 汉字九宫格：口/古/十、们/闫/仨、圣/土/问号。
  - 答案：汉字加减同异：前两字去同存异得第三字。

**关联**：字母与单词（K1-10-2）

## 字母与单词　★★

`K1-10-2`

单字母看曲直、面、对称；多字母与单词看元素种类、相同元素数量、曲直位置、字母变形翻转。

**识别信号**
- A、B、C 或成串英文单词
- 字母被拉伸/翻转

**解题步骤**
1. 单字母：曲直、封闭面、对称
2. 多字母：数曲线字母与直线字母的数量/位置
3. 单词：数相同字母、元音数量、元素接龙

**规则 / 公式 / 结论**
- 元素接龙：末字母接下一词首字母（ZHAO→OH→HOU）

**易错**
- 把大小写混为一类

**例题**
- 九宫格字母：T/M/A、S/N/Z、H/O/问号，选项 D、E、W、I。
  - 答案：按字母对称性（轴对称/中心对称）分行排列。

**关联**：汉字（K1-10-1）

## 数字与 Logo / 实物简笔　★★

`K1-10-3`

数字看面数量、对称、曲线数、直角数（变形数字）；Logo 与实物简笔看部分数、对称、笔画。

**识别信号**
- 数字被折角化（角变形）
- 黑色粗线条 logo、实物轮廓

**解题步骤**
1. 数字变形：数直角或面
2. 普通数字：数封闭面（0、6、8、9）
3. Logo：粗线条、成团 → 数部分数、对称、笔画

**规则 / 公式 / 结论**
- 「数字修正变形」几乎只考直角数量

**易错**
- 把数字当文字去数笔画

**例题**
- 变形数字 1–8 的九宫格 + 问号，选项为变形 9、6、5。
  - 答案：数直角个数，按行递增。

**关联**：部分数（K1-8-2）
