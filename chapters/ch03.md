# 第一部分 · 图形推理 · 三、样式类：图形相似，做加减

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

图形长得像、有叠加痕迹时，考的是「同与异」的运算。

## 叠加：求同、求异、去同存异　★★★

`K1-3-1`

两图叠加后保留相同部分（求同）、保留不同部分（求异）或去掉相同保留不同（去同存异）。

**识别信号**
- 前两图相似，第三图是运算结果
- 九宫格中每行/列三图

**解题步骤**
1. 把图 1、图 2 叠在一起，逐块比对
2. 判断保留的是「同」还是「异」
3. 用第三行验证规则是否一致

**规则 / 公式 / 结论**
- 去同存异常伴随「元素减少」，且不依赖外轮廓

**易错**
- 把「求同」的残留看成新元素

**例题**
- 九宫格前两行均为「图1 + 图2 = 图3」，第三行缺图 3。
  - 答案：前两行元素叠加后去同存异，按同一规则补第三行。

**关联**：黑白运算（K1-3-2）

## 黑白运算　★★★

`K1-3-2`

相同位置上黑、白（或黑、灰）按固定规则相加：黑+白=黑、黑+黑=白等，规则由前两行给出。

**识别信号**
- 图形相似、有黑块/阴影
- 九宫格或两图相加得第三图

**解题步骤**
1. 从前两行同一位置读出「黑+白」「黑+黑」「白+白」的结果
2. 把规则列成小表
3. 套到缺图的位置上逐格填

**规则 / 公式 / 结论**
- 规则必须三行通用；若某格对不上，说明看错了位置

**易错**
- 忽略「黑+黑=白」这类反直觉规则
- 把位置对错（旋转后再运算）

**例题**
- 两图黑块叠加得第三图，第三行缺图。
  - 答案：由前两行读出黑+白=黑、黑+黑=白，再逐格套用。

**关联**：叠加运算（K1-3-1）

## 遍历（元素出现次数）　★★

`K1-3-3`

同一组元素在每行/每列中各出现固定次数，缺什么补什么。

**识别信号**
- 元素种类固定、只是排列不同
- 九宫格每行元素种类一致

**解题步骤**
1. 统计每种元素在行/列中的出现次数
2. 找出缺失的种类或次数

**规则 / 公式 / 结论**
- 遍历看「种类齐不齐」，不看位置

**易错**
- 把「每行都有」误判成「每种各一次」

**例题**
- 九宫格内圆、方、三角每行各出现一次。
  - 答案：补齐缺失元素即可，位置不重要。

**关联**：元素种类与个数（K1-8-1）
