# 第一部分 · 图形推理 · 四、数量类·面：封闭区域

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

面是图推第一数量考点。先数总数，无规律再换「形状、大小、位置、曲直、对称」。

## 面数量（封闭区域数）　★★★

`K1-4-1`

数封闭区域的个数；生活化图形、粗线条留白、汉字字母数字、立体图都可数面。

**识别信号**
- 图形有明显封闭区域
- 面数呈 1、2、3、4、5 或递增/递减

**解题步骤**
1. 只数「完全封闭」的区域，开口不算
2. 黑块把空白分割时，数被分割出的空白面
3. 总数无规律 → 试「隔项」「行和」「列和」

**规则 / 公式 / 结论**
- 面相对好数，是杂乱图形的首选
- 黑白题中常数「空白面」而非黑块数

**易错**
- 把开口区域算成面
- 把外框本身算成一个面

**例题**
- 九宫格汉字（Σ、3、圭 / R、兄、Ⅱ / ?、侣、⑥），选项为新、洲、有、齐。
  - 答案：按行数封闭面，第三行需 2 个面 → 选「有」。
- 黑箭头、月牙、镰刀形等四格 + 问号，数空白面。
  - 答案：空白面 1、2、3、4、5 递增 → 选空白面为 5 的选项。

**关联**：面的形状（K1-4-2）；最大/最小面（K1-4-3）

## 面的形状：三角形、四边形与「只看 X 边形」　★★★

`K1-4-2`

面数无规律时，改数「特定形状的面」：三角形个数、四边形个数、二者做差，或「a 个 M 边形 + b 个 N 边形」。

**识别信号**
- 图形被分割成多个多边形
- 每个图都由三角形/四边形组成

**解题步骤**
1. 先单独数三角形，再单独数四边形
2. 两者都无规律 → 做差/做和
3. 出现重复计数（同一三角形被多条线分割）时，按「重复数」计

**规则 / 公式 / 结论**
- 原稿：单独数、重复数、做差三种考法
- 正方形、长方形多时同理可数

**易错**
- 漏数被分割出的小三角形
- 把重复计数与单独计数混用

**例题**
- 正方形被分割成若干三角形与四边形，五格 + 问号。
  - 答案：四边形数减三角形数恒为 1 → 选差值相同的选项。

**关联**：面数量（K1-4-1）

## 最大面 / 最小面　★★★

`K1-4-3`

出现明显的最大面或最小面时，看它的形状、边数、对称性、曲直、面积占比、相对位置。

**识别信号**
- 图形被一条斜线分成一大一小
- 存在明显的主面

**解题步骤**
1. 先定位最大面/最小面
2. 按「边数 → 对称 → 曲直 → 与外框相似 → 面积占比 → 位置」顺序逐项试
3. 两项都无规律 → 试「最大面与最小面形状相同」

**规则 / 公式 / 结论**
- 原稿六看：曲直、形状、对称、面积占比、位置关系、与外框相似

**易错**
- 把「最大面」与「外框」混淆

**例题**
- 五格分割图 + 问号，最大面形状与外框一致。
  - 答案：最大面边数等于外框边数 → 选同规律的选项。
- 分割图 + 问号，最大面为轴对称图形。
  - 答案：看最大面是否轴对称（其余为不对称），选轴对称的一项。

**关联**：相同面/相似面（K1-4-4）

## 相同面 / 相似面 / 圆内面 / 对称面　★★

`K1-4-4`

面数无规律时的四类延伸：出现成对相同面、面与外框相似、圆内被分割的面、轴对称的面。

**识别信号**
- 面数对不上但图形中反复出现同一形状
- 中部有共同圆、圆内分割越来越多
- 面内有明显对称形状

**解题步骤**
1. 相同面：数「成对相同」的面对数
2. 相似面：看内面与外轮廓是否相似、是否有平行边
3. 圆内面：只数圆内部被分割出的面
4. 对称面：数轴对称面的个数

**规则 / 公式 / 结论**
- 圆内面、对称面属较新考点，遇到「圆+分割」优先试

**易错**
- 把「相同面」数成「总面数」

**例题**
- 五格图形，每图都含一个共同的圆，圆内分割逐渐增多。
  - 答案：圆内面 1、2、3、4、5 → 选圆内面为 6 的选项。
- 方形内不同分割 + 问号，看轴对称面数量。
  - 答案：轴对称面 0、1、2、3、4、5 → 选 6 个的一项。

**关联**：面的形状（K1-4-2）

## 直线面 / 曲线面　★★

`K1-4-5`

整体面数无规律、但去掉某图就成规律时，改数「直线围成的面」或「曲线围成的面」。

**识别信号**
- 方框套圆、圆套方、圆内分割、田字格
- 面数差一个就对不上

**解题步骤**
1. 分别数直线面与曲线面
2. 看单类是否成等差
3. 两类都试，取能贯穿全部图形的那一类

**规则 / 公式 / 结论**
- 「去掉某图就成规律」是典型信号

**易错**
- 把曲线围成的面算进直线面

**例题**
- 圆套方、方分二、圆内分割、田字格等五格 + 问号。
  - 答案：直线围成的面 1、2、3、4、5、6。

**关联**：面数量（K1-4-1）
