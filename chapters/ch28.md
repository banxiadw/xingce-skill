# 第六部分 · 数字推理 · 一、总纲：判别顺序与试错纪律

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

顺序错了，算得再对也白费。先分类，再试方法，两次不成就换路。

## 四步判别链（项数 → 差距 → 外形 → 兜底）　★★★

`K6-1-1`

拿到数列先做四件事：数项数、看相邻差距、看外形（根号/分数/小数/多位数）、都不行再走因式分解、圈三数、看选项。

**识别信号**
- 任何数字推理题的第一步
- 尤其是真题中「看不出规律」的题

**解题步骤**
1. 数项数：≥7 项优先想分组（奇偶、两两、三三）
2. 看差距：差距小做差，差距大（2–3 倍）做商，数字普遍很小做和
3. 看外形：根号→统一根式；分数→分子分母分列；小数→整数/小数分列；多位数→拆数位
4. 都不成：因式分解、圈三数找递推、用选项反推

**规则 / 公式 / 结论**
- 数列长（≥7 项）→ 想分组；数列短 → 想多级
- 「空格不在最后一项，就需要去猜，大胆验证」

**易错**
- 一上来就做差，连做四五次仍不换路
- 忽略外形（分数/根式）直接当整式处理

**例题**
- 1，4，9，16，25，（ ）
  - 答案：外形贴平方数：1²、2²、3²、4²、5² → 6² = 36。

**关联**：试错纪律（K6-1-2）

## 试错纪律：两次即停、一次即换　★★

`K6-1-2`

做差两次没有规律就停，做商一次没有规律就停，转做和或分组；每题只保留一条能解释全列的规律。

**识别信号**
- 考场时间压力下的取舍
- 多个方法都「差不多能凑」时

**解题步骤**
1. 做差：最多两层，第二层无规律立即转
2. 做商：只做一次，商不成等差/等比/幂次就转
3. 得到规律后必须回代验证全部项，含选项

**规则 / 公式 / 结论**
- 「差两次即停、商一次即停」
- 多解时选能解释全部项、且形式最简单的那条

**易错**
- 为了凑规律强行加修正项
- 用最后一项倒推规律（会过拟合）

**例题**
- 2，3，5，9，17，33，（ ）
  - 答案：做差得 1、2、4、8、16（等比），下一差 32 → 65。

**关联**：四步判别（K6-1-1）

## 基础数列清单（必须背）　★★★

`K6-1-3`

质数列、合数列、平方数、立方数、2 的幂、阶乘、斐波那契，是识别「像什么」的对照表。

**识别信号**
- 数字贴近某个幂次或质数
- 做差后出现 2、3、5、7、11……

**解题步骤**
1. 把数列与基础数列对照（±1、±2 内）
2. 记住平方 1–20、立方 1–11、2 的 1–10 次方
3. 质数至少背到 50 以内

**规则 / 公式 / 结论**
- 平方：1,4,9,16,25,36,49,64,81,100,121,144,169,196,225,256,289,324,361,400

**易错**
- 把 1 当质数
- 忘记 0 和负数也可能是幂次项

**例题**
- 2，3，5，7，11，（ ）
  - 答案：质数列，下一个质数是 13。

**关联**：幂次数列（K6-4-1）
