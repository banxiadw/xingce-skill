# 第一部分 · 图形推理 · 九、属性类：对称、曲直、开闭、连接

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

数量数不出来时，回到属性：对称怎么对称、曲直怎么组合、开还是闭、怎么连。

## 对称：方式、方向、轴数　★★★

`K1-9-1`

判轴对称/中心对称/不对称，再看对称轴方向（横/竖/斜）、数量（1 条、2 条、多条）与位置关系。

**识别信号**
- 图形规整、可对折
- 黑白块整体或单独对称

**解题步骤**
1. 先判是否对称、哪种对称
2. 对称方向：相同、顺逆时针、递推
3. 轴数：相等、递增、加和、按数量分组、交替

**规则 / 公式 / 结论**
- 两个图形相接：看两对称轴平行/垂直/相交
- 三个图形（一黑两白）：看黑块对称轴与白块关系
- 轴对称 + 中心对称可同时成立

**易错**
- 把「中心对称」误判为「轴对称」
- 漏数斜向对称轴

**例题**
- 方框加斜线、四角星、椭圆、方框内斜线、三角形+方框 + 问号。
  - 答案：数对称轴条数（1、2、3…），按等差补图。
- 对称轴与内部线条的关系（重合/垂直/平行）。
  - 答案：看轴上是否有线条——重合/垂直/平行三种关系轮换。

**关联**：对称面（K1-4-4）

## 曲直性与开闭性　★★

`K1-9-2`

整图是纯直、纯曲还是有曲有直；图形是封闭的还是开放的。

**识别信号**
- 曲直线混杂、图形有开口
- 轮廓与内部曲直不同

**解题步骤**
1. 定性：纯直/纯曲/曲直混合
2. 开闭：有无开口
3. 内外组合：外曲内直、外直内曲

**规则 / 公式 / 结论**
- 「内外都乱定性看」——内外形状都不规则时只看曲直

**易错**
- 把一段圆弧当成直线

**例题**
- 三角形内曲线、圆内三角、云形内方块等五格。
  - 答案：外曲内直/外直内曲的定性轮换。

**关联**：内外结构（K1-5-5）

## 连接方式（点连接 / 线连接）　★★

`K1-9-3`

多个图形之间是点接触还是边接触；相邻公共边数量、对接方式（完全/不完全/交错）、对接夹角都是考点。

**识别信号**
- 几个图形拼在一起
- 有公共边或相切点

**解题步骤**
1. 先分「点连接/边连接」
2. 边连接数公共边数量
3. 再看对接方式与夹角

**规则 / 公式 / 结论**
- 点连接的图形通常一笔画

**易错**
- 把「边上相接」当成「点相接」

**例题**
- 两个三角形点连接、两个星形点连接、方框角对角相接等六图。
  - 答案：全部为点连接 → 均为一笔画。

**关联**：笔画数（K1-5-2）
