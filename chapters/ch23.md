# 第四部分 · 逻辑判断（上）：逻辑论证 · 二、一般质疑

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

不针对归因，而是针对「论据—结论」之间的推理缺口：论据本身有错、论据不足、论据与结论断链、结论无中生有。

## 无论据有结论　★

`K4-2-1`

题干由背景、分析、结论组成而没有硬论据；质疑方式是提出**反向论据**。

**识别信号**
- 题干没有数据、实验、调查，只有道理和判断

**解题步骤**
1. 确认题干确实没有事实论据
2. 构造与结论相反的事实或反例
3. 核对话题一致、主体正确、贴合题干

**规则 / 公式 / 结论**
- 反向论据必须落在同一话题、同一主体上

**易错**
- 答非所问（换了主体或范围）
- 只表达态度不给论据

**例题**
- 题干：本市应全面禁摩，因为摩托车影响市容。以下哪项最能质疑？
  - 答案：本市摩托车事故率与拥堵贡献率均低于私家车，且是部分低收入群体的通勤工具——反向论据。

**关联**：有论据有结论（K4-2-2）

## 有论据有结论（四种拆法）　★★★

`K4-2-2`

题干有论据也有结论；按缺口分四类：质疑论据、增加反向论据、断点拆桥、结论无中生有。

**识别信号**
- 题干含调查/数据/研究结论
- 结论往往比论据更进一步

**解题步骤**
1. 先判断论据本身是否可靠（个人观点、样本问题 → 质疑论据）
2. 再看论据是否只覆盖有利面（考虑不全面）或以少数推全部（以偏概全）→ 增加反向论据
3. 若论据与结论概念不衔接 → 拆桥
4. 若结论出现论据没有的新内容且程度较重 → 质疑「无中生有」

**规则 / 公式 / 结论**
- 对比实验归因可视为特殊的「质疑论据」
- 拆桥优先于举例：拆桥直接断推理，举例只是弱支持/弱削弱

**易错**
- 拿「另有他因」硬套非因果题
- 把「重复论据」当加强

**例题**
- 题干：某调查显示 80% 的用户满意，故产品体验优秀。以下哪项最能质疑？
  - 答案：调查只覆盖了主动留下评价的用户，未评价者多为不满者——质疑样本（以偏概全）。
- 题干：某地引进人才后 GDP 增速提高，故人才政策见效。
  - 答案：同期该地获得大额基建投资——增加反向论据（考虑不全面）。

**关联**：严谨逻辑关系质疑（K4-2-3）

## 严谨逻辑关系质疑（A 且非 B）　★★★

`K4-2-3`

结论含逻辑关联词，可翻译为 A→B；削弱即找「A 且非 B」，少数题可用「A→非 B」替代。

**识别信号**
- 结论出现「如果…就」「只有…才」「所有…都」
- 问法为质疑/削弱

**解题步骤**
1. 把结论翻译为 A→B
2. 在选项中找 A 成立而 B 不成立的实例
3. 核对 A、B 是否为题干原概念（偷换即错）

**规则 / 公式 / 结论**
- A→B 为假，当且仅当 A 真且 B 假（前件真、后件假）

**易错**
- 用「非 A 且 B」冒充（这是后件真，命题仍真）
- 把充分必要方向译反

**例题**
- 结论：只要加强监管就能杜绝造假。以下哪项最能质疑？
  - 答案：某地监管力度全国最强，造假案件却同比增长——A 且非 B。

**关联**：假言命题（K5-1-1）

## 比例类论证　★★

`K4-2-4`

题干用「分子的多少」代替「分子/分母的比例」下结论；削弱时补出分母。

**识别信号**
- 题干出现绝对数字（人数、件数、金额）
- 结论为「更危险/更普遍/更高发」

**解题步骤**
1. 识别绝对数 → 比例的偷换
2. 在选项中找带数字的分母（基数）
3. 比较两组比例而非数量

**规则 / 公式 / 结论**
- 比例题常可秒杀：正确项必带分母数据

**易错**
- 选项只重复分子
- 选项给的是无关年份的分母

**例题**
- 题干：A 市交通事故数高于 B 市，故 A 市交通更危险。
  - 答案：A 市机动车保有量是 B 市的 5 倍——补出分母，事故率反而更低。

**关联**：有论据有结论（K4-2-2）
