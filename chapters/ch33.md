# 第六部分 · 数字推理 · 六、小数与根式数列

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

两种「外形特殊」的数列，各有固定拆法。

## 小数数列：分列与内部运算　★★

`K6-6-1`

整数部分与小数部分分列；或对同一项内部做加减（和成倍、差成平方）。

**识别信号**
- 每项带小数点且位数一致
- 整数部分递增、小数部分跳动

**解题步骤**
1. 整数列、小数列分别找规律
2. 试整数+小数、整数−小数
3. 试隔项成倍

**规则 / 公式 / 结论**
- 「小数位 = 整数各位数字和/差」也是常见伪装

**易错**
- 把 3.2 当 32 处理

**例题**
- 3.2，5.7，8.5，12.9，17.8，（ ）
  - 答案：整数列做差为 2,3,4,5；小数列另成规律，合并得下一项 75.85 型（见原页）。

**关联**：根式数列（K6-6-2）

## 根式数列：统一根式、内外拆分　★★

`K6-6-2`

先统一根指数或统一成 b√x 形式；不成再把根号内外分别成列。

**识别信号**
- 出现 √2、³√5、2√3 等
- 根号内数字递增

**解题步骤**
1. 统一根指数（如都化成平方根）
2. 写成 b√x：b 列与 x 列分别找规律
3. 带根指数时看 3,5,7,9 的奇数列

**规则 / 公式 / 结论**
- 「根号内外之和为平方数」是统一失败后的退路

**易错**
- 不同根指数直接相加

**例题**
- √2，2√3，3√5，4√7，（ ）
  - 答案：系数 1、2、3、4；根号内 2、3、5、7 为质数 → 5√11。

**关联**：小数数列（K6-6-1）
