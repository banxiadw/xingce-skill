# 第六部分 · 数字推理 · 四、幂次数列：贴表找修正

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

看到 9、16、25、27、64 这类数，先想「这是几的几次方」。

## 基本幂次：平方、立方、2ⁿ　★★★

`K6-4-1`

通项为 n²、n³、2ⁿ、n! 等，或它们的组合；「注意多次方附近的数值」。

**识别信号**
- 数字贴近 4,9,16,25,36 / 8,27,64,125
- 单调且增长加速

**解题步骤**
1. 把每项写成幂次
2. 看底数、指数是否分别成规律
3. 不成再看修正

**规则 / 公式 / 结论**
- 平方数表 1²–20²、立方表 1³–11³ 必须记熟

**易错**
- 只认平方不认立方
- 忽略 1 和 0 的特殊性

**例题**
- -1，2，6，21，43，（ ）
  - 答案：各项贴近立方：0³−1、1³+1、2³−2、3³−6、4³−21…按修正规律推得 82。

**关联**：幂次修正（K6-4-2）

## 幂次修正（n³+1、平方+1 与立方−1 交替）　★★★

`K6-4-2`

每项 = 幂次 ± 一个小的常数或数列，修正项本身可能有规律。

**识别信号**
- 差值序列正好是 1、2、3…或 1、4、9…
- 数字离幂次只差一点

**解题步骤**
1. 写出最接近的幂次
2. 求修正项并找规律
3. 修正项可为常数、等差、交替

**规则 / 公式 / 结论**
- 「平方+1 与立方−1 交替」是常见变体

**易错**
- 修正项只验证一半就定案

**例题**
- 2，5，10，17，26，（ ）
  - 答案：各项 = n² + 1（1²+1、2²+1…）→ 6²+1 = 37。

**关联**：基本幂次（K6-4-1）

## 底数/指数同时变化与分数指数　★★

`K6-4-3`

底数成等差、指数成等差，或出现 1/n、n^(-1) 这类负数次方。

**识别信号**
- 每项可写成 aᵇ 且 a、b 各自有规律
- 出现 1/2、1/4、1/8 与整数混排

**解题步骤**
1. 统一写成幂形式
2. 分别看底数列、指数列
3. 负指数：1/n = n^(-1)

**规则 / 公式 / 结论**
- 「1 与 1/n 相邻 → 负数次方」

**易错**
- 把 1/8 只当分数，不写成 2^(-3)

**例题**
- 1，4，27，256，（ ）
  - 答案：通项 nⁿ：1¹、2²、3³、4⁴ → 5⁵ = 3125。

**关联**：幂次修正（K6-4-2）
