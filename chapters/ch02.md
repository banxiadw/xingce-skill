# 第一部分 · 图形推理 · 二、位置类：图形没变，只是挪了地方

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

元素相同、轮廓一致，差异只在位置与方向。

## 平移（含折返跑、只动一行/列）　★★★

`K1-2-1`

元素沿直线或外框按固定格数移动；到端点后折返的称「折返跑」，只有一行/列变化的称「只动一行/列」。

**识别信号**
- 轮廓一致、阴影或元素数量基本一致
- 黑点沿一行、一列或外圈移动

**解题步骤**
1. 先确认元素个数没有增减
2. 选一个基准元素，标记它在相邻图中的位移（几格、什么方向）
3. 到端点后是折返还是绕回，用第二、三图验证

**规则 / 公式 / 结论**
- 平移题必须「同元素、同数量」，否则转数量类

**易错**
- 把「旋转」看成「平移」
- 只看一个元素，忽略另一个元素反向移动

**例题**
- 1×12 长条点阵，黑点逐格右移，到最右端后下一格出现在左端附近。
  - 答案：单向平移 + 折返：到端点后反向，步长不变。

**关联**：旋转与翻转（K1-2-2）

---

## 旋转与翻转　★★★

`K1-2-2`

组成部分相同、方向不同：能通过平面旋转得到的为旋转，必须镜像才能得到的为翻转。

**识别信号**
- 图形相同但朝向不同
- 出现字母、箭头、不对称图形

**解题步骤**
1. 取一个不对称特征（缺口、黑块、字母方向）作为参照
2. 按 90°/180° 试旋转，看能否重合
3. 不能重合但呈镜像 → 翻转（左右翻或上下翻）

**规则 / 公式 / 结论**
- 旋转不改变手性；翻转改变手性（左右手互换）

**易错**
- 把翻转当成旋转（尤其字母 b/d、p/q）

**例题**
- 四格黑白方块，后一格是前一格整体转动 90°。
  - 答案：整体旋转：以黑块所在角为参照，顺时针 90° 递推。

**关联**：平移（K1-2-1）

## 缺口位置与位置传递　★★

`K1-2-4`

规则点阵中缺一个点（缺口），或阴影分布密集时，用「缺口位置移动」「位置传递」推进。

**识别信号**
- 点阵中少一个点
- 阴影密集、轮廓规则（位置传递）

**解题步骤**
1. 标出缺口坐标，看逐图位移
2. 阴影密集时看「上一图哪块传到下一图」
3. 用行列坐标或象限描述位置

**规则 / 公式 / 结论**
- 位置传递要求轮廓规则、阴影密集
- 缺口题常与「点数」数量规律叠加

**易错**
- 把缺口当成印刷瑕疵

**例题**
- 5×4 圆点阵，每图缺一个点，缺口位置逐图变化。
  - 答案：按缺口所在行列的位移（如每次右移一格、到底折返）递推。

**关联**：平移（K1-2-1）

## 元素位置关系（相邻、相对、互换）　★★

`K1-2-5`

多个小元素在固定轮廓内改变相对位置：相邻变相对、左上与右下互换、沿弧线转动到相同位置。

**识别信号**
- 田字格/方格内 3–4 个小元素
- 元素种类不变，位置在换

**解题步骤**
1. 给每个元素编号
2. 记录每图的位置序列
3. 找「互换对」或「整体转动」的规律

**规则 / 公式 / 结论**
- 相同元素按顺序画弧线，可判断顺/逆时针

**易错**
- 把两个元素的互换看成整体旋转

**例题**
- 田字格内四个小图案，逐图位置轮换。
  - 答案：相邻或相对位置变化：按顺时针逐个顶替。

**关联**：平移（K1-2-1）
