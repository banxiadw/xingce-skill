# 第四部分 · 逻辑判断（上）：逻辑论证 · 三、支持 · 前提 · 解释

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

三类问法共用「补缺口」逻辑：支持是让结论更可信，前提是让结论能成立（没他不行），解释是让现象说得通。

## 五种常见支持方式　★★★

`K4-3-1`

解释说明、断点搭桥、增加正向论据、必要条件（反向代入）、举例支持——按力度与适用场景排序使用。

**识别信号**
- 问法：最能加强/支持上述论证、上述发现

**解题步骤**
1. 先看结论有没有论据中没有的「新内容」——有则优先找搭桥
2. 论据有漏洞 → 补漏洞（增加正向论据）
3. 结论是因果/机制 → 找解释说明
4. 问「需要前提/假设」→ 用反向代入验必要条件

**规则 / 公式 / 结论**
- 断点搭桥：结论新内容必须在选项中出现，并与论据关键信息连接
- 必要条件：反向代入后结论不成立，才是「没他不行」
- 举例支持力度弱于搭桥与正向论据；类比支持基本不是答案

**易错**
- 把「有他更好」当成「没他不行」
- 选项重复题干论据（无增量）
- 举例支持与类比支持混淆（类比是多对象相似，力度最弱）

**例题**
- 8 周实验：早餐前锻炼组脂肪燃烧量为早餐后组 2 倍，胰岛素反应改善，故早餐前锻炼更降低心血管疾病风险。以下哪项最能支持？
  - 答案：脂肪量过高是罹患心血管疾病的主要原因——把「脂肪燃烧」与「心血管风险」搭桥。
- 专家称分心驾驶是引发我国交通事故常见且重要的原因。以下哪项最能支持？
  - 答案：我国交通事故致因中酒驾占 1/3、分心驾驶占 1/2——用数据说明「重要」。

**关联**：三种前提假设（K4-3-2）

## 三种前提假设　★★★

`K4-3-2`

断点搭桥、补充漏洞、必要条件/能与不能；前提是「结论成立必须有」的条件，力度不要求极强但不可或缺。

**识别信号**
- 问法：需要补充的前提是、还需隐含哪项假设

**解题步骤**
1. 找结论中论据没有的新概念 → 搭桥
2. 找论证缺的那块事实 → 补漏洞
3. 涉及「能否做到/是否存在」→ 必要条件（能与不能）

**规则 / 公式 / 结论**
- 搭桥项往往看似「废话」，但把新概念接回论据
- 补充漏洞常表现为排除某种反向可能（如「不是 B 导致 A」）

**易错**
- 选了加强项但不是必要项（有他更好 ≠ 没他不行）

**例题**
- CGRP 可增强造血干细胞动员，专家认为吃辣可促进造血干细胞动员。需要补充的前提是？
  - 答案：辛辣食物的「辣味」是一种痛觉，会激活伤害感受神经——把「吃辣」接到 CGRP 通路。
- 虎山长城除一号台址有少量残砖外均未发现城砖，附近村庄也没有拆砖用于民房，故推测虎山长城用砖极少。
  - 答案：此地山高坡陡，城砖难以运进运出——补漏洞：砖根本运不进来。

**关联**：五种支持方式（K4-3-1）

## 解释说明类　★★

`K4-3-3`

题干给出一个看似矛盾的现象，要求选出能说明「为什么会这样」的选项。

**识别信号**
- 问法：最能解释这一现象/这一情况
- 题干含转折：但、然而、却

**解题步骤**
1. 找出矛盾的两端（预期 vs 实际）
2. 在选项中找能同时兼容两端的机制
3. 排除只解释一端、或与题干角度不符的选项

**规则 / 公式 / 结论**
- 选项要针对题干讨论的角度（主观需求 vs 客观价格、个体 vs 群体）
- 「法律规定」「政策要求」类选项一般无解释力
- 重复题干论据的选项不是答案

**易错**
- 把「不能解释」当成「解释得少」
- 选择与矛盾无关的第三方信息

**例题**
- 音乐节首次邀请知名交响乐团，主办方预计一票难求，开票后却并非如此。以下哪项最能解释？
  - 答案：演出门票价格过高——不是需求不高，而是价格劝退（客观原因解释反差）。
- 导游说清代神道较近、坡缓、好走，小马走了一半却抱怨台阶又多又陡。
  - 答案：明代神道的台阶更多更陡——差异是两个对象之间的比较，不是人的体力差异。

**关联**：五种支持方式（K4-3-1）
