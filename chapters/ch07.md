# 第一部分 · 图形推理 · 七、数量类·角：直角为主

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

角考得最多的是直角，其次是锐角与扇形夹角。

## 直角数量　★★★

`K1-7-1`

数图形中的直角个数；H、T、工、L 形、电话卡（缺角方框）是典型载体。

**识别信号**
- 折线、方框、缺角图形
- 「故意多一笔/少一笔」

**解题步骤**
1. 先找天然垂直（方框四角）
2. 数直角个数，看递增/相等
3. 纯黑图形只看黑色区域的直角

**规则 / 公式 / 结论**
- 点不行还可以看直角——交点数无规律时的替补

**易错**
- 把钝角/锐角混入
- 漏掉延伸线形成的直角

**例题**
- 九宫格折线符号 1–8 + 问号，左侧另有圆圈内 T。
  - 答案：按行数直角，H/T/工/L 型最易识别。

**关联**：锐角与夹角（K1-7-2）

## 锐角与扇形夹角　★★

`K1-7-2`

锐角看 Z 字形、三角形及其变形；扇形面看圆心角（夹角度数）。

**识别信号**
- Z、M、N 形折线
- 扇形、半圆帽形

**解题步骤**
1. 数锐角个数
2. 扇形题看角度大小（30°/60°/90° 等）
3. 也可按「锐角/直角/钝角」分列

**规则 / 公式 / 结论**
- 原稿：特殊角按列分为锐角、直角、钝角；外框直角数递增

**易错**
- 把钝角算成锐角

**例题**
- Z、M、✕、双 M、N 形折线 + 问号。
  - 答案：数锐角个数，按等差递推。

**关联**：直角（K1-7-1）
