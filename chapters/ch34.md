# 第六部分 · 数字推理 · 七、分组与机械拆分

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

项数多、位数多时的两条路：按位置分组，或按数位拆开。

## 奇偶分组（交叉数列）　★★★

`K6-7-1`

奇数项、偶数项各自成列，两列各有规律；常与幂次、等差组合。

**识别信号**
- 项数 ≥7
- 相邻项忽大忽小

**解题步骤**
1. 拆成奇数列、偶数列
2. 分别判断规律
3. 两列规律可不同（一列等差、一列等比）

**规则 / 公式 / 结论**
- 「数列长，想分组」

**易错**
- 两列规律搞混，回填位置错

**例题**
- 1，2，3，4，5，8，7，（ ）
  - 答案：奇数列 1、3、5、7；偶数列 2、4、8、16 → 16。

**关联**：两两/三三分组（K6-7-2）

## 两两分组、三三分组（组内和/积恒定）　★★★

`K6-7-2`

两两一组看组内和、差、积、倍；三三一组看 a+b=c 或组内递推。

**识别信号**
- 项数为偶数且规律不明显
- 组内数字关系比相邻项更紧

**解题步骤**
1. 两两分组，算组内和/积/商
2. 组和成等差、等比或恒定
3. 三三分组试 a+b=c

**规则 / 公式 / 结论**
- 组内乘积恒定、组和为常数是高频套路

**易错**
- 分组起点错位（从第二项开始分组）

**例题**
- 1，2，3，6，5，10，7，（ ）
  - 答案：两两分组 (1,2)(3,6)(5,10)(7,14)，组内后项是前项 2 倍 → 14。

**关联**：奇偶分组（K6-7-1）

## 数位拆分（多位数两截/数位和）　★★★

`K6-7-3`

把多位数拆成前后两段（如 1234 → 12|34）或拆成各位数字，分别成列。

**识别信号**
- 出现四五位数
- 各数位数一致

**解题步骤**
1. 统一从中间劈开成两列
2. 或求各位数字之和/差
3. 两列各自找规律

**规则 / 公式 / 结论**
- 「差 = 前项数位和」「后两位差 = 各位数字和」是常见伪装

**易错**
- 位数不统一却硬拆

**例题**
- 12，23，35，48，（ ）
  - 答案：差为 11、12、13 → 下一差 14，48+14 = 62。

**关联**：两两/三三（K6-7-2）

---

## 因式分解（全合数、提公因数）　★★

`K6-7-4`

每项都能拆成「两个有规律的因子」，如等差×质数、n×(n+1)。

**识别信号**
- 数列全是合数
- 数值跳跃但都能整除某个数

**解题步骤**
1. 逐项分解质因数
2. 把因子排成两列找规律
3. 提公因数后再看剩余列

**规则 / 公式 / 结论**
- 「全合数 → 先因式分解」

**易错**
- 忘记 1 的处理

**例题**
- 2，6，12，20，30，（ ）
  - 答案：因式分解 n(n+1)：1×2、2×3、3×4… → 6×7 = 42。

**关联**：数位拆分（K6-7-3）
