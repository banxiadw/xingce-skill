# 第六部分 · 数字推理 · 五、分数数列：分子分母分列

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

分数题的四条路：分列、反约分、通分、伪分数。

## 分子分母各成列　★★★

`K6-5-1`

把每项的分子、分母分别写成两列，各自找规律（等差、等比、和递推）。

**识别信号**
- 一列分数，分子分母都在变

**解题步骤**
1. 分列写出分子列、分母列
2. 各自判断规律
3. 必要时两列互相递推

**规则 / 公式 / 结论**
- 「分子分母互相递推」——分子由上一项分母加减得到

**易错**
- 先通分再看，导致规律被掩盖

**例题**
- 1/2，2/5，3/10，4/17，（ ）
  - 答案：分子为 1,2,3,4；分母 2,5,10,17 差为 3,5,7 → 分母 26，答案 5/26。

**关联**：反约分/通分（K6-5-2）

## 反约分与通分　★★★

`K6-5-2`

反约分：把已约分的分数还原成同向规律；通分：统一分母后再做差。

**识别信号**
- 分母参差不齐但接近倍数
- 选项分母提示了公分母

**解题步骤**
1. 先看选项分母，反推通分目标
2. 通分后分子做差
3. 或反约分使分子/分母同向

**规则 / 公式 / 结论**
- 「选项的分母 → 通分」是刷题高频技巧

**易错**
- 通分后忘记约分回选项

**例题**
- 1/2，2/6，3/12，4/20，（ ）
  - 答案：分子 1、2、3、4；分母 n(n+1) = 2、6、12、20 → 5/30 = 1/6。

**关联**：分子分母分列（K6-5-1）

## 伪分数：实为多级或递推　★★

`K6-5-3`

分数只是「外形」，实际规律在数值本身：做差、做积、做商。

**识别信号**
- 分数值本身成等差/等比
- 分子分母没有独立规律

**解题步骤**
1. 算出每项的数值
2. 对数值做差/做商/做积
3. 如做积恒为质数、做差为等比

**规则 / 公式 / 结论**
- 「可约分 → 做积为质数」是一种典型伪分数

**易错**
- 死盯分子分母，忽略数值规律

**例题**
- 1/2，2/3，3/5，5/8，（ ）
  - 答案：分子分母各自为前两项之和（斐波那契型）→ 8/13。

**关联**：试错纪律（K6-1-2）
