# 第三部分 · 类比推理 · 二、语法关系：词在句中充当什么成分

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

两词或三词能组成一个短语/句子时，看主谓、动宾、偏正。

## 主谓 / 主谓宾　★★★

`K3-2-1`

前者是主体、后者是动作或陈述；三词时可能是「主语 + 宾语 + 谓语」。

**识别信号**
- 两词可组成主谓句
- 三词可连成一句完整的话

**解题步骤**
1. 造一个包含所有词的句子
2. 标出主、谓、宾
3. 三词题还要比褒贬

**规则 / 公式 / 结论**
- 「学生∶知识∶死记硬背」＝主+宾+谓，且含贬义

**易错**
- 把动宾当主谓
- 忽略三词题的褒贬一致

**例题**
- 学生∶知识∶死记硬背
  - 答案：主+宾+谓且为贬义；应选「农民∶庄稼∶揠苗助长」。

**关联**：偏正（K3-2-2）

---

## 偏正结构　★★★

`K3-2-2`

前词修饰后词（定中/状中）；比喻式偏正（人潮、夜幕）是高频变体。

**识别信号**
- 前词是修饰语（形容词/名词作定语）
- 后词是中心语

**解题步骤**
1. 把前词加「的」看能否修饰后词
2. 区分动宾（后词是对象）与偏正（后词是中心）
3. 比喻式偏正：两词都是「像…一样的…」

**规则 / 公式 / 结论**
- 「明眸∶善睐」＝偏正 + 特点；「人潮∶夜幕」＝两个比喻式偏正并列

**易错**
- 把偏正当主谓（础润/知雨）
- 忽略比喻式偏正

**例题**
- 明眸∶善睐
  - 答案：明眸是偏正，善睐是其特征；应选「老马∶识途」。
- 人潮∶夜幕
  - 答案：两个比喻式偏正并列；应选「浪花∶火海」。

**关联**：主谓宾（K3-2-1）

---

## 动宾与并列短语　★★

`K3-2-3`

前词是动作、后词是对象（动宾）；两词地位对等则为并列。

**识别信号**
- 前词是动词（扬汤、止沸）
- 两词可互换位置不改变关系

**解题步骤**
1. 判断能否加「了」构成动宾
2. 并列则看词性是否一致
3. 动宾注意方向（先动作后对象）

**规则 / 公式 / 结论**
- 「扬汤∶止沸」是动宾，不是偏正，也不是主谓

**易错**
- 把动宾看成目的关系（扬汤是为了止沸）

**例题**
- 扬汤∶止沸
  - 答案：动宾结构，且两词有先后动作关系。

**关联**：偏正（K3-2-2）
