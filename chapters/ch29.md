# 第六部分 · 数字推理 · 二、多级数列：做差、做商、做和

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

整式数列的第一反应，占真题近半。核心是「几层、什么形态」。

## 做差（含正负交替、二次差）　★★★

`K6-2-1`

相邻两项相减，看差数列是否为等差、等比、质数、平方或周期；一次不成再做第二次。

**识别信号**
- 数列单调、差距不大且逐渐变化
- 数字在 10–100 之间

**解题步骤**
1. 一次差：看是否等差/周期
2. 二次差：看是否等差、常数、质数
3. 正负交替：差本身正负交替，考虑符号与绝对值分开看

**规则 / 公式 / 结论**
- 二次差为常数 → 原数列是二次函数型（aₙ=an²+bn+c）
- 三次差才出规律 → 立方型，回代时别少加一层

**易错**
- 只做一层就放弃
- 二次差算出后忘记回推到原数列

**例题**
- 2，5，11，23，47，（ ）
  - 答案：差 3、6、12、24（等比），下一差 48 → 95。

**关联**：做商（K6-2-3）

## 做和（含做和成等比/质数/平方）　★★

`K6-2-2`

相邻两项相加得新数列，新数列常为等比、质数、平方或立方。

**识别信号**
- 数字普遍偏小（≤20）
- 做差做商都无规律

**解题步骤**
1. 两两求和
2. 看和数列的形态（等比/质数/幂次）
3. 必要时再做一次和

**规则 / 公式 / 结论**
- 「先做差，再求和」——差值有规律但接不上时，改用和

**易错**
- 和数列与原数列混用（把和当成下一项）

**例题**
- 1，2，3，5，8，13，（ ）
  - 答案：典型两项和递推 → 21（本质是递推，不是多级）。

**关联**：递推（K6-3-1）

## 做商（倍数、倍数等差）　★★★

`K6-2-3`

相邻两项相除，看商是否等差、等比、幂次或「倍数 ± 常数」。

**识别信号**
- 相邻项呈 2 倍、3 倍关系
- 「差距已经到 2 倍、3 倍时，差距就大了」

**解题步骤**
1. 后项除前项（或前除后，看哪个方向有规律）
2. 商为等差 → 倍数递增
3. 商含分数 → 化为分数再找规律

**规则 / 公式 / 结论**
- 倍数型常写成 aₙ₊₁ = k·aₙ + b，b 为常数或等差

**易错**
- 除不尽就放弃（小数/分数商也可能是规律）

**例题**
- 1，3，9，27，81，（ ）
  - 答案：商恒为 3 → 243。

**关联**：乘积递推（K6-3-3）

---

## 多级组合：先差后商、差后作商　★★

`K6-2-4`

差数列本身再做商，或商数列再做差；真题中常以「两级不同方法」出现。

**识别信号**
- 差数列是倍数关系
- 商数列是等差

**解题步骤**
1. 先做差，得到新数列
2. 对新数列做商/做差
3. 回推两层

**规则 / 公式 / 结论**
- 多级组合题必须回推两层，漏一层即错项

**易错**
- 回推时把层数搞错

**例题**
- 1，2，6，24，120，（ ）
  - 答案：做商：2、3、4、5，下一商 6 → 720。

**关联**：试错纪律（K6-1-2）
