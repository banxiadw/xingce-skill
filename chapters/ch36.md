# 第七部分 · 数学运算 · 一、计算与方程：把文字变成式子

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

数量关系的地基：设元、整除、余数、等差与平方数，决定了后面所有题的速度。

## 和差倍比与设元（倍数/比例/倍数链）　★★★

`K7-1-1`

按「谁是谁的几倍/几分之几」设未知数：倍数设 x 与 kx，比例设份数，倍数链设最小公倍。

**识别信号**
- 题干出现「是…的 3 倍」「占 40%」「甲比乙多」

**解题步骤**
1. 找基准量，设为 x
2. 倍数关系写成 kx，比例关系设成 3 份、5 份
3. 多个倍数串联时，设最内层为 x，逐层外推
4. 列等式：总量相同、时间轴相同、盈亏相同

**规则 / 公式 / 结论**
- 「倍数链设元」：A=2B、B=3C 时设 C=x，则 B=3x、A=6x，全是整数

**易错**
- 设了分数导致方程难解
- 忘记总量守恒

**例题**
- 甲乙丙三数，甲是乙的 2 倍，乙是丙的 3 倍，三数之和为 100，求丙。
  - 答案：设丙 = x，则乙 = 3x、甲 = 6x，10x = 100 → x = 10。

**关联**：不定方程（K7-1-3）

## 方程法：时间轴、总量相同、调度表　★★★

`K7-1-2`

三类高频列式场景：时间轴（年龄、工期）、总量相同（户均×户数）、调度表（人员/车辆分配）。

**识别信号**
- 题干有「几年后」「同时开工」「每户」
- 多个对象按不同方案分配

**解题步骤**
1. 时间轴：设现在为 x，前后年份统一用 x±n 表示
2. 总量相同：写出两条路径的总量表达式并相等
3. 调度表：画表，行是对象、列是方案，空格设未知数

**规则 / 公式 / 结论**
- 「总量相同」是最稳的等量关系，优先找它

**易错**
- 年龄题忘记「年龄差不变」
- 调度表行列建反

**例题**
- 父亲今年 40 岁，儿子 12 岁，几年后父亲年龄是儿子的 2 倍？
  - 答案：设 x 年后：40 + x = 2(12 + x) → x = 16。

**关联**：和差倍比（K7-1-1）

## 不定方程四法（奇偶/尾数/倍数/代入）　★★★

`K7-1-3`

未知数多于方程时，用整除性质缩小范围：奇偶性、尾数、倍数、选项代入。

**识别信号**
- ax + by = c 型，求整数解
- 问「至少/最多/可能」

**解题步骤**
1. 先看奇偶：两边奇偶必须一致
2. 再看尾数：系数含 5 或 10 时看末位
3. 再看倍数：某项是 3 的倍数则另一项也受限
4. 最后把选项代入验证

**规则 / 公式 / 结论**
- 「a±b 同倍」：a、b 都能被 m 整除，则 a±b 也能被 m 整除

**易错**
- 忘记未知数必须是非负整数

**例题**
- 3x + 5y = 31（x、y 均为正整数），求全部解。
  - 答案：奇偶 + 尾数：y 为偶数且 5y 尾数 0 或 5；y = 2 时 x = 7，y = 5 时 x = 2，共两组。

**关联**：整除特性（K7-1-4）

## 整除特性（3/9/2/5/4/25/8/125）　★★★

`K7-1-4`

用分数的分母、倍数关系直接锁定选项：化最简后分母即倍数，末几位判 4/8/25/125。

**识别信号**
- 题干出现分数、百分数、比例
- 问「多少人」「多少件」必须是整数

**解题步骤**
1. 把比例化最简，分母即「总数必须是它的倍数」
2. 看末一位判 2/5，末两位判 4/25，末三位判 8/125
3. 各位数字和判 3/9

**规则 / 公式 / 结论**
- 「占比反推」：占 3/7 → 总数是 7 的倍数，直接筛选项

**易错**
- 忘记先约分，用未化简的分母判断

**例题**
- 某班人数占全年级的 3/7，全年级人数可能是多少？
  - 答案：全年级人数必为 7 的倍数（如 140），据此直接筛选项。

**关联**：不定方程（K7-1-3）

## 余数三口诀与同余　★★

`K7-1-5`

余同取余、和同加和、差同减差；都不满足时用「最小公倍数 + 余数」构造。

**识别信号**
- 「除以 3 余 2，除以 5 余 2」
- 问「最少有多少」

**解题步骤**
1. 余数相同 → 取余数 + k×lcm
2. 除数与余数的和相同 → 取和 + k×lcm
3. 除数与余数的差相同 → 取差 + k×lcm

**规则 / 公式 / 结论**
- 三口诀：余同取余、和同加和、差同减差

**易错**
- lcm 用错（应取所有除数的最小公倍数）

**例题**
- 一个数除以 4 余 1、除以 5 余 1，最小是多少？
  - 答案：余同取余：lcm(4,5) = 20，20 + 1 = 21。

**关联**：整除特性（K7-1-4）

## 等差数列：通项、求和、中项秒杀　★★★

`K7-1-6`

aₙ = a₁ + (n−1)d；Sₙ = n(a₁+aₙ)/2；奇数项时 Sₙ = n × 中项。

**识别信号**
- 「连续」「每天多 1」「第 n 排」
- 求和且项数为奇数

**解题步骤**
1. 先定 a₁ 与 d
2. 求和优先用中项公式（奇数项）
3. 三角形/方阵排列用「层数 × 中项」

**规则 / 公式 / 结论**
- S奇 = n × 中项，是最快的秒杀式

**易错**
- 项数数错（含首尾）

**例题**
- 某剧院第一排 20 个座位，以后每排比前一排多 2 个，共 15 排，求总座位数。
  - 答案：a₁=20，d=2，a₁₅=48，S=15×(20+48)/2=510。

**关联**：平方数（K7-1-7）

## 平方数/立方数速记与年龄平方　★

`K7-1-7`

1²–20²、1³–11³ 必背；常见考法「年龄的平方等于年份」。

**识别信号**
- 出现年份 + 年龄
- 数字接近完全平方

**解题步骤**
1. 把年份写成平方数
2. 反推年龄
3. 注意 45²=2025 这类近年平方

**规则 / 公式 / 结论**
- 45²=2025、44²=1936，是年龄题的常用锚点

**易错**
- 把平方数记混

**例题**
- 某人在 2025 年的年龄恰好是 2025 的平方根，他多少岁？
  - 答案：45² = 2025 → 45 岁。

**关联**：等差数列（K7-1-6）
