# 第六部分 · 数字推理 · 八、图形数阵与应试策略

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

九宫格、表格、圆形数阵，本质是「行/列/圈内运算」。

## 图形数阵（九宫格、表格、圆形）　★★

`K6-8-1`

在九宫格或圆环中找行内、列内或圈内的加减乘除关系，常见「行内求和/求积」「对角相等」。

**识别信号**
- 数字排成方阵或圆圈
- 某行/列数字关系明显

**解题步骤**
1. 先试行内求和/差
2. 再试列内
3. 最后试对角、外圈、中心与周围

**规则 / 公式 / 结论**
- 九宫格优先「每行三数一个算式」

**易错**
- 只看行不看列

**例题**
- 九宫格每行三数：第一行 2、3、5；第二行 4、5、9；第三行 6、7、？
  - 答案：每行满足 a + b = c → 6 + 7 = 13。

**关联**：试错纪律（K6-1-2）

## 选项反推与蒙题策略　★★

`K6-8-2`

从选项形态反推规律类型：分子统一→反约分；带 .5→1/2 倍递推；根式→内外之和。

**识别信号**
- 时间不足或规律卡住
- 选项差异有特征

**解题步骤**
1. 看选项是否同分母、同根号、带小数
2. 据此反推最可能的规律
3. 用该规律验证前几项

**规则 / 公式 / 结论**
- 「选项 B/D 数值相近 → 用整数部分趋势蒙」

**易错**
- 完全不验证就选

**例题**
- 1/2，1/3，1/5，1/8，（ ）
  - 答案：分母差为 1、2、3 → 下一分母 12，答案 1/12（选项分母统一时优先反约分对表）。

**关联**：四步判别（K6-1-1）
