# 第一部分 · 图形推理 · 五、数量类·线：直线、曲线、笔画、平行、延伸

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

线考点分两层：先数「线条本身」，再看「线与线的关系」（平行、延伸、出头）。

## 直线数 / 曲线数　★★★

`K1-5-1`

数直线条数或曲线条数；可只看内部、只看外轮廓，也可内外做差/求和。

**识别信号**
- 纯直线图形、纯曲线图形
- 外框固定、内部线条数变化

**解题步骤**
1. 先定性：纯直、纯曲、有曲有直
2. 纯直 → 数直线；纯曲 → 数曲线
3. 内外都有 → 分别数，再试「差/和/相等」

**规则 / 公式 / 结论**
- 复杂程度不单调时，做差/做和往往出规律

**易错**
- 把一条折线数成多条直线
- 曲线与直线交点计入线数

**例题**
- 五边形套五边形、米字、竖条等图形 + 问号。
  - 答案：内外直线数做差（或相等），按差值序列选。

**关联**：内外结构（K1-5-5）

---

## 笔画数（奇点判定）　★★★

`K1-5-2`

笔画数 = 奇点数 ÷ 2；奇点为 0 或 2 时可一笔画成。日字变形、出头多的图形是典型载体。

**识别信号**
- 图形像「日」或「田」的变形
- 线条有出头、交叉复杂

**解题步骤**
1. 数每个交点的连线数，奇数条即为奇点
2. 奇点 0 或 2 → 一笔画；4 个 → 两笔画
3. 结果常呈 1、2、3 递增

**规则 / 公式 / 结论**
- 端点也算奇点
- 一笔画与「点连接」高度相关

**易错**
- 漏数端点
- 把「面数」当笔画数

**例题**
- B 形、方块内斜线、缺口圆、六边形、屋形等图形。
  - 答案：均为日字变形，按奇点数判笔画，呈递增规律。

**关联**：交点数量（K1-6-1）

---

## 平行线　★★

`K1-5-3`

数平行线的组数；自带平行线的图形（矩形、梯形、平行四边形）与 H、Z、N、工 形是典型载体。

**识别信号**
- 图形由直线构成且有明显平行边
- 九宫格中平行组数变化

**解题步骤**
1. 先找天然平行（矩形对边）
2. 数「平行线组数」而非线条数
3. 看组数是相同、递增还是递减

**规则 / 公式 / 结论**
- 组数相同/递增/递减三种规律最常见

**易错**
- 把同一组内的两条线数成两组

**例题**
- 九宫格 9 个「刀/旗」形折线符号。
  - 答案：数平行线组数，按行递增。

**关联**：直线数（K1-5-1）

---

## 延伸线（含迷惑型）　★★

`K1-5-4`

图形外的短出头线；可数根数、看方向、做加和，也可能只是迷惑项，真正考的是外框。

**识别信号**
- 图形带「尾巴」
- 回旋/蛇形折线

**解题步骤**
1. 先数延伸线根数，看是否成规律
2. 再看方向（平行/垂直）与位置
3. 若延伸线无规律，回到外框线条

**规则 / 公式 / 结论**
- 出现延伸线不代表一定考它——「迷惑型延伸线」考外框

**易错**
- 见尾巴就数，忽略外框规律

**例题**
- 两组带点的短折线，末格为问号。
  - 答案：两组延伸线加和都为 8。

**关联**：内外结构（K1-5-5）

## 内外结构（外看边、内看点线面）　★★★

`K1-5-5`

轮廓固定、内部变化时：外看边数与边上点，内看点/线/面，二者可混合运算。

**识别信号**
- 外框相同（圆、方、扇面），内部图形变化
- 外部规则、内部杂乱，或反之

**解题步骤**
1. 外部规则必须看：外轮廓边数/形状
2. 轮廓相同都要看：中心区域形状、对角线方向、直角
3. 内外都乱 → 看曲直定性（外曲内直/外直内曲）
4. 内外数量可做差、求和、相等

**规则 / 公式 / 结论**
- 原稿五句：外看边/边上点；内看点/线/面；有出头看交点；线条清晰数线；面看数量/形状/位置

**易错**
- 被内部杂乱干扰，漏看外轮廓规律

**例题**
- 六格圆内不同分割，答案注「中心区域形状」。
  - 答案：轮廓相同 → 看中心区域形状（圆/方/三角）变化。
- 方形内对角线方向逐图变化。
  - 答案：轮廓相同看「对角线方向」，按 45° 递推。

**关联**：直线数（K1-5-1）；曲直交点（K1-6-2）
