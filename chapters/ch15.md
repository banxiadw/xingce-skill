# 第二部分 · 定义判断 · 三、题型分类：多定义、具体型、抽象型

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

题型不同，读法不同：多定义先看设问，具体型抓被定义词，抽象型抓关系。

## 多定义（设问指向）　★★★

`K2-3-1`

题干给两个以上定义，先看设问问的是哪一个，再比对几个定义的差异与共性。

**识别信号**
- 题干分条列出多个定义（时期数列/时点数列）
- 设问指定其中一个

**解题步骤**
1. 先读设问，锁定目标定义
2. 把目标定义的「区别点」单独标出（如「能否相加」）
3. 用区别点筛选项，不必读完所有定义

**规则 / 公式 / 结论**
- 多定义的关键是「差异点」，不是每个定义的全文

**易错**
- 从头读到尾，读完忘了问的是哪个

**例题**
- 时期数列（可相加）与时点数列（不可相加），问属于时点数列的是。
  - 答案：「年末员工人数」不可相加 → 选 B。
- 车流摩阻 / 交会摩阻 / 交叉摩阻，问说法不正确的是。
  - 答案：双车道一侧中断、上下行交替通行属于交会摩阻，不是交叉摩阻 → 选 B。

**关联**：具体型单定义（K2-3-2）

## 具体型单定义（被定义词是关键）　★★★

`K2-3-2`

题干只有一个定义，被定义词直白具体；重点看被定义词（多为偏正短语），定义部分只是解释。

**识别信号**
- 被定义词本身就能看懂（动机性遗忘、可持续交通）
- 定义句很长

**解题步骤**
1. 拆被定义词：偏（修饰）+ 正（中心），两者都不能丢
2. 用中心语定范畴（遗忘/交通/调查）
3. 用修饰语定特殊限定（动机性/可持续/社会）

**规则 / 公式 / 结论**
- 只看「偏」会漏掉中心语，只看「正」会漏掉限定

**易错**
- 把修饰语当全部，忽略中心语的范围

**例题**
- 动机性遗忘：下列属于的是。
  - 答案：脑震荡/阿尔兹海默属病理性遗忘；「不愿回忆」不等于真遗忘；火灾幸存者忘记此事 → 选该项。
- 可持续交通：下列不属于的是。
  - 答案：养牛场耳标与「交通」无关 → 选 D。

**关联**：抽象型单定义（K2-3-3）

## 抽象型单定义（关系类）　★★★

`K2-3-3`

定义描述的是两者/三者之间的关系或结构，需先还原关系模型，再逐项代入。

**识别信号**
- 定义含「两者之间」「相互作用」「结构与性能」
- 选项都是成对/成组关系

**解题步骤**
1. 把定义写成关系式（A 与 B 的某种关系）
2. 标出关系的方向、对称性、条件
3. 逐项代入检验是否满足该关系

**规则 / 公式 / 结论**
- 关系类定义的核心是「方向」与「是否对称」

**易错**
- 只抓关键词，不还原关系

**例题**
- R 关系的非对称性。
  - 答案：先判断关系是否对称，再逐项代入；对称的关系不满足定义。
- 胆小鬼博弈。
  - 答案：先还原「双方各自让步/坚持」的收益结构，再对照选项。

**关联**：多定义（K2-3-1）
