# 第五部分 · 逻辑判断（下）：逻辑推理 · 六、分析类：真假话与日常推理

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

没有固定翻译套路，靠矛盾、假设、代入、画表、赋值五种工具推进。

## 真假话：矛盾法 · 假设法 · 代入法　★★★

`K5-3-1`

先找矛盾对锁定真假，再用假设推进；无矛盾时用代入排除。

**识别信号**
- 题干若干人各说一句话
- 给出「只有一人为真/为假」

**解题步骤**
1. 翻译每句话，标出矛盾对（必一真一假）
2. 由真假总数推出矛盾对之外命题的真假
3. 仍不确定时假设某一命题为真，检查是否自洽
4. 题干信息多且无矛盾 → 直接代入选项排除

**规则 / 公式 / 结论**
- 矛盾对必一真一假，是解题的锚点
- 涉及「有些/所有」时从特例入手
- 「或者/至少」类命题在假设中通常为真

**易错**
- 把反对关系当矛盾关系
- 假设后不回代验证

**例题**
- 张教练：没人会达标；孙教练：有队员会达标；王教练：省运会冠军或国家队队员可达标。只有一位预测正确。
  - 答案：没有人达标——「所有不」与「特指」是反对关系可同假，唯一为真的是孙教练的「有些」。

**关联**：两真两假模型（K5-3-2）

## 两真两假模型　★★

`K5-3-2`

四个命题两真两假：先找矛盾对，再假设一点，推出其余真假。

**识别信号**
- 题干四个断言、明确两真两假

**解题步骤**
1. 配对矛盾
2. 假设某一支为真，推出全组真假分布
3. 检查是否恰好两真两假

**规则 / 公式 / 结论**
- 矛盾对占去一真一假，剩余两命题必一真一假

**易错**
- 假设后不核验总数
- 忽略「前件假则命题真」

**例题**
- ①两人至少一个考上；②甲不必然考上；③乙考上；④并非甲可能没考上。两真两假。
  - 答案：甲考上、乙没考上——②与④矛盾；假设甲考上则④真②假，①③中仅一真。

**关联**：真假话三法（K5-3-1）

## 日常分析：画表 · 画图 · 赋值　★★★

`K5-3-3`

多人多属性匹配用画表；位置与相邻关系用画图（圆桌拉直）；大小比较用赋值。

**识别信号**
- 若干人、若干地点/专业/名次
- 相邻、左右、围坐
- 纳税多少、分数高低

**解题步骤**
1. 从确定信息、最大信息入手
2. 画表：行是人、列是属性，确定信息先填
3. 画图：圆桌按顺时针拉成直线，箭头表示相邻
4. 赋值：给未知量取具体数字，检验选项

**规则 / 公式 / 结论**
- 确定信息 > 最大信息 > 假设
- 一题两问时，第一问的结论可用于第二问

**易错**
- 表格行列建反
- 赋值时取了特殊值导致误判

**例题**
- 5 人分到 3 个小区，每区 1–2 人；南山最少；邓或丁在南山则吴在北苑；孔邓丁有人在东江则北苑只有洪。
  - 答案：邓、丁在北苑（东江为吴、洪，孔在南山）——由「北苑不能只有一人」反推。

**关联**：特殊模型（K5-3-4）

## 五类特殊模型　★★★

`K5-3-4`

不同角度分类、包含关系、多重身份、数独、冠军模型——识别模型即可套固定解法。

**识别信号**
- 分类计数（师范/非师范 × 男/女）
- 包含关系（哈尔滨人属于北方人）
- 一人多身份（专业 + 城市 + 学校）
- 九宫格/4×4 填词
- 多人预测、只有一人通过

**解题步骤**
1. 分类模型：设未知数，列不等式比较两边
2. 包含模型：先合并同类，再求最少/最多
3. 多重身份：画二维表，确定信息先填，再找唯一空位
4. 数独：从唯一候选格突破
5. 冠军：把每句话改成「或」，被所有人提到的人不是冠军

**规则 / 公式 / 结论**
- 包含关系求「最少」时让集合尽量重叠，求「最多」时尽量分离
- 多重身份中「农业和江苏抱团」这类线索用于锁定唯一空位

**易错**
- 最少/最多方向搞反
- 多重身份题重复使用同一线索导致矛盾

**例题**
- 1 个哈尔滨人、2 个北方人、1 个广东人、2 个只做电子设备生意、3 个只做服装生意，涉及桌上所有人。最少/最多几人？
  - 答案：最少 5 人、最多 8 人——哈尔滨人属于北方人，先合并再按是否重叠计算。

**关联**：日常分析（K5-3-3）
