# 第五部分 · 逻辑判断（下）：逻辑推理 · 四、逻辑基础：命题与翻译

> 星级：★★★ 必考 / ★★ 核心 / ★ 高频。本技能不含原稿图片，图形题请结合原始笔记。

五个符号、四种关系、五种关联词——所有推出类题目的地基。

## 假言命题与五种关联词　★★★

`K5-1-1`

如果…那么（前推后）、只有…才（后推前）、除非…否则（否 A 推 B）、或者…或者（否一推一）、要么…要么（一真一假）。

**识别信号**
- 题干出现关联词
- 问法：可以推出/不能推出

**解题步骤**
1. 圈出关联词，按「前推后/后推前」写出箭头
2. 「只有 A 才 B」记作 B→A，也可记「不 A 不 B」
3. 「除非 A 否则 B」记作 非 A→B
4. 多个命题先别急着联立，先看选项需要哪一句

**规则 / 公式 / 结论**
- A→B 等价于 非 B→非 A（逆否），等价于 非 A 或 B（否前或后）
- 「如果 A 那么 B」的否定是「A 且非 B」
- 充分条件在箭头前，必要条件在箭头后（谁是必要条件谁放箭头后）

**易错**
- 把必要条件当充分条件（「只有…才」译成 A→B）
- 「除非…否则」漏掉否定
- 把「a、b」并列句译成推出关系（它是「且」）

**例题**
- 没有人民支持和参与，任何改革都不可能取得成功；只有充分尊重人民意愿且形成广泛共识，人民才会积极支持改革。可以得出？
  - 答案：只有人民支持和参与，改革才可能取得成功——把「没有…不可能」还原为「成功→支持参与」。
- 「吃得苦中苦，方为人上人。」据此不能推出？
  - 答案：「若能吃得苦中苦，则能成为人上人」——「方」＝「才」，原句是「成为人上人→吃得苦中苦」，该项方向反了。

**关联**：命题真假与矛盾（K5-1-4）；等价推出（K5-2-1）

## 联言命题与选言命题　★★★

`K5-1-2`

且（同时存在，一假则假）与或（至少一个，一真则真）；相容选言「或者」、不相容选言「要么」。

**识别信号**
- 「并且、也、还、同时、，」→ 且
- 「或者、至少一个、至多一个」→ 或

**解题步骤**
1. 「A 和 B 至少一个」→ A 或 B
2. 「A 和 B 至多一个」→ 非 A 或 非 B
3. 「要么 A 要么 B」→ 一真一假，不能同真同假

**规则 / 公式 / 结论**
- 非（A 且 B）＝ 非 A 或 非 B；非（A 或 B）＝ 非 A 且 非 B
- 「或者」的等价：A 或 B ＝ 非 A→B ＝ 非 B→A（否一推一）
- 「要么」的矛盾：（A 且 B）或（非 A 且 非 B）

**易错**
- 把「至多一个」译成「A 或 B」
- 把相容选言当不相容用

**例题**
- 「或者去北京，或者去上海」可以推出？
  - 答案：不去北京就去上海——否一推一。

**关联**：假言命题（K5-1-1）

## 模态命题与直言命题　★★★

`K5-1-3`

必然/可能、所有/有些的否定与推出关系；记忆口诀「两词互换，后面加不」。

**识别信号**
- 「必然、可能、一定、也许」
- 「所有、有些、有的、特指」

**解题步骤**
1. 否定：「所有→有些不」「有些→所有不」「必然→可能不」「可能→必然不」
2. 推出：所有→特指→有些；必然→可能
3. 「有些 A 是 B」可推出「有些 B 是 A」，但推不出「有些 A 不是 B」

**规则 / 公式 / 结论**
- 上反对（两个所有）必有一假；下反对（两个有些）必有一真
- 矛盾关系必有一真一假；反对关系可同真或同假

**易错**
- 「有些不」与「有些」当矛盾（实为下反对）
- 把「有些是」当「有些不是」

**例题**
- 「并非所有同学都及格」等价于？
  - 答案：有些同学不及格——「所有…都」的否定是「有些不」。

**关联**：命题真假与矛盾（K5-1-4）

## 命题真假与矛盾关系　★★★

`K5-1-4`

A→B 仅在「A 真且 B 假」时为假；矛盾关系三类：性质、或且、推出与且非。

**识别信号**
- 问「只有一个为真/为假」
- 问「与题干真假情况相同」

**解题步骤**
1. 先翻译每个命题
2. 找矛盾对（必一真一假）
3. 剩余命题按「假设法」或「反对关系」推进

**规则 / 公式 / 结论**
- 矛盾关系：A 与非 A；所有与有些不；可能不与必然；A→B 与 A 且非 B；A 且 B 与 非 A 或非 B
- 前件假则命题真，后件真则命题真（钱建伟 / 侯建真）

**易错**
- 把反对关系当矛盾关系
- 忘记「前件假命题真」导致误判

**例题**
- 4 张卡片一面字母一面数字，可见 A、B、5、8；主持人称「若一面是 A，则另一面是 5」。要推翻需翻哪两张？
  - 答案：A 与 8——只有 A 真而 5 假时才推翻；B 前件假、5 后件真，均不足以推翻。

**关联**：真假话分析（K5-3-1）
