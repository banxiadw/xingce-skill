# 输出约定

识别一道题时，按下面五段回答，不要直接给答案：

1. **题型**：属于七个部分中的哪一个（图形推理 / 定义判断 / 类比推理 / 逻辑论证 / 逻辑推理 / 数字推理 / 数学运算）。
2. **考点**：考点 ID + 名称 + 星级（如 `K1-5-2 笔画数 ★★★`）。
3. **判据**：题干里哪句话、哪个特征让你这么判断（引用原文关键词）。
4. **方法**：该考点的解题步骤（3–5 步），必要时给公式。
5. **易错**：这类题最常见的 1–2 个陷阱，以及本题要怎么避开。

如果需要继续解题，再单独给「解」这一段，与上面的识别结论分开写。

## 不确定时

- 给 2 个候选考点并说明区分点（例如「种属 vs 组成」）。
- **不要编造**原笔记里没有的考点或公式。
- 图形题只看文字描述无法确定时，明确说「需要原图」。
