一、总纲：四步观察与排除顺序

先定大方向，再定小考点；顺序错了，数得再准也白费。

K1-1-1

图形推理四步观察法

★★★

看元素是否相同 → 看轮廓是否相同 → 看图形是否相似 → 看是否杂乱，分别对应位置、样式、数量、属性四条主线。

识别信号

  • 一组 5–9 个图形，多为九宫格或一条线
  • 问号在末格或中间格

解题步骤

  1. 元素完全相同：优先位置（平移、旋转、翻转）
  2. 轮廓相同、内部变化：优先内外结构（外看边、内看点线面）
  3. 图形相似、有叠加痕迹：优先样式（求同、求异、黑白运算）
  4. 图形杂乱无章：优先数量（点、线、面、角、素）与属性（对称、曲直、开闭）
  5. 数量与属性都无解时，再看特殊载体（汉字、字母、数字、Logo）与立体

判分规则 / 结论

  • 原稿口诀：外看边/边上点；内看点/线/面；有出头看交点；线条清晰数线；面看数量/形状/位置
  • 「先外后内，别被干扰」——轮廓相同时先看轮廓本身

易错与反模式

  • 一上来就数面，忽略位置规律
  • 九宫格只看行不看列（行、列、S 形都要试）

对应题目

Q001图形推理四步观察法B-27 原页

九宫格 8 图 + 问号，图形轮廓完全相同、内部线条不同。

答案/解析：先看轮廓（外轮廓边数/形状），再看内部点、线、面——属「轮廓相同都要看」，不是数量类。

关联： 内外结构 属性：对称

二、位置类：图形没变，只是挪了地方

元素相同、轮廓一致，差异只在位置与方向。

K1-2-1

平移（含折返跑、只动一行/列）

★★★

元素沿直线或外框按固定格数移动；到端点后折返的称「折返跑」，只有一行/列变化的称「只动一行/列」。

识别信号

  • 轮廓一致、阴影或元素数量基本一致
  • 黑点沿一行、一列或外圈移动

解题步骤

  1. 先确认元素个数没有增减
  2. 选一个基准元素，标记它在相邻图中的位移（几格、什么方向）
  3. 到端点后是折返还是绕回，用第二、三图验证

判分规则 / 结论

  • 平移题必须「同元素、同数量」，否则转数量类

易错与反模式

  • 把「旋转」看成「平移」
  • 只看一个元素，忽略另一个元素反向移动

对应题目

Q002平移（含折返跑、只动一行/列）B-24 原页

1×12 长条点阵，黑点逐格右移，到最右端后下一格出现在左端附近。

答案/解析：单向平移 + 折返：到端点后反向，步长不变。

关联： 旋转与翻转

K1-2-2

旋转与翻转

★★★

组成部分相同、方向不同：能通过平面旋转得到的为旋转，必须镜像才能得到的为翻转。

识别信号

  • 图形相同但朝向不同
  • 出现字母、箭头、不对称图形

解题步骤

  1. 取一个不对称特征（缺口、黑块、字母方向）作为参照
  2. 按 90°/180° 试旋转，看能否重合
  3. 不能重合但呈镜像 → 翻转（左右翻或上下翻）

判分规则 / 结论

  • 旋转不改变手性；翻转改变手性（左右手互换）

易错与反模式

  • 把翻转当成旋转（尤其字母 b/d、p/q）

对应题目

Q003旋转与翻转B-24 原页

四格黑白方块，后一格是前一格整体转动 90°。

答案/解析：整体旋转：以黑块所在角为参照，顺时针 90° 递推。

关联： 平移

K1-2-4

缺口位置与位置传递

★★

规则点阵中缺一个点（缺口），或阴影分布密集时，用「缺口位置移动」「位置传递」推进。

识别信号

  • 点阵中少一个点
  • 阴影密集、轮廓规则（位置传递）

解题步骤

  1. 标出缺口坐标，看逐图位移
  2. 阴影密集时看「上一图哪块传到下一图」
  3. 用行列坐标或象限描述位置

判分规则 / 结论

  • 位置传递要求轮廓规则、阴影密集
  • 缺口题常与「点数」数量规律叠加

易错与反模式

  • 把缺口当成印刷瑕疵

对应题目

Q004缺口位置与位置传递B-14 原页

5×4 圆点阵，每图缺一个点，缺口位置逐图变化。

答案/解析：按缺口所在行列的位移（如每次右移一格、到底折返）递推。

关联： 平移

K1-2-5

元素位置关系（相邻、相对、互换）

★★

多个小元素在固定轮廓内改变相对位置：相邻变相对、左上与右下互换、沿弧线转动到相同位置。

识别信号

  • 田字格/方格内 3–4 个小元素
  • 元素种类不变，位置在换

解题步骤

  1. 给每个元素编号
  2. 记录每图的位置序列
  3. 找「互换对」或「整体转动」的规律

判分规则 / 结论

  • 相同元素按顺序画弧线，可判断顺/逆时针

易错与反模式

  • 把两个元素的互换看成整体旋转

对应题目

Q005元素位置关系（相邻、相对、互换）B-36 原页

田字格内四个小图案，逐图位置轮换。

答案/解析：相邻或相对位置变化：按顺时针逐个顶替。

关联： 平移

三、样式类：图形相似，做加减

图形长得像、有叠加痕迹时，考的是「同与异」的运算。

K1-3-1

叠加：求同、求异、去同存异

★★★

两图叠加后保留相同部分（求同）、保留不同部分（求异）或去掉相同保留不同（去同存异）。

识别信号

  • 前两图相似，第三图是运算结果
  • 九宫格中每行/列三图

解题步骤

  1. 把图 1、图 2 叠在一起，逐块比对
  2. 判断保留的是「同」还是「异」
  3. 用第三行验证规则是否一致

判分规则 / 结论

  • 去同存异常伴随「元素减少」，且不依赖外轮廓

易错与反模式

  • 把「求同」的残留看成新元素

对应题目

Q006叠加：求同、求异、去同存异B-25 原页

九宫格前两行均为「图1 + 图2 = 图3」，第三行缺图 3。

答案/解析：前两行元素叠加后去同存异，按同一规则补第三行。

关联： 黑白运算

K1-3-2

黑白运算

★★★

相同位置上黑、白（或黑、灰）按固定规则相加：黑+白=黑、黑+黑=白等，规则由前两行给出。

识别信号

  • 图形相似、有黑块/阴影
  • 九宫格或两图相加得第三图

解题步骤

  1. 从前两行同一位置读出「黑+白」「黑+黑」「白+白」的结果
  2. 把规则列成小表
  3. 套到缺图的位置上逐格填

判分规则 / 结论

  • 规则必须三行通用；若某格对不上，说明看错了位置

易错与反模式

  • 忽略「黑+黑=白」这类反直觉规则
  • 把位置对错（旋转后再运算）

对应题目

Q007黑白运算B-25 原页

两图黑块叠加得第三图，第三行缺图。

答案/解析：由前两行读出黑+白=黑、黑+黑=白，再逐格套用。

关联： 叠加运算

K1-3-3

遍历（元素出现次数）

★★

同一组元素在每行/每列中各出现固定次数，缺什么补什么。

识别信号

  • 元素种类固定、只是排列不同
  • 九宫格每行元素种类一致

解题步骤

  1. 统计每种元素在行/列中的出现次数
  2. 找出缺失的种类或次数

判分规则 / 结论

  • 遍历看「种类齐不齐」，不看位置

易错与反模式

  • 把「每行都有」误判成「每种各一次」

对应题目

Q008遍历（元素出现次数）B-35 原页

九宫格内圆、方、三角每行各出现一次。

答案/解析：补齐缺失元素即可，位置不重要。

关联： 元素种类与个数

四、数量类·面：封闭区域

面是图推第一数量考点。先数总数，无规律再换「形状、大小、位置、曲直、对称」。

K1-4-1

面数量（封闭区域数）

★★★

数封闭区域的个数；生活化图形、粗线条留白、汉字字母数字、立体图都可数面。

识别信号

  • 图形有明显封闭区域
  • 面数呈 1、2、3、4、5 或递增/递减

解题步骤

  1. 只数「完全封闭」的区域，开口不算
  2. 黑块把空白分割时，数被分割出的空白面
  3. 总数无规律 → 试「隔项」「行和」「列和」

判分规则 / 结论

  • 面相对好数，是杂乱图形的首选
  • 黑白题中常数「空白面」而非黑块数

易错与反模式

  • 把开口区域算成面
  • 把外框本身算成一个面

对应题目

九宫格汉字（Σ、3、圭 / R、兄、Ⅱ / ?、侣、⑥），选项为新、洲、有、齐。

K1-4-2

面的形状：三角形、四边形与「只看 X 边形」

★★★

面数无规律时，改数「特定形状的面」：三角形个数、四边形个数、二者做差，或「a 个 M 边形 + b 个 N 边形」。

识别信号

  • 图形被分割成多个多边形
  • 每个图都由三角形/四边形组成

解题步骤

  1. 先单独数三角形，再单独数四边形
  2. 两者都无规律 → 做差/做和
  3. 出现重复计数（同一三角形被多条线分割）时，按「重复数」计

判分规则 / 结论

  • 原稿：单独数、重复数、做差三种考法
  • 正方形、长方形多时同理可数

易错与反模式

  • 漏数被分割出的小三角形
  • 把重复计数与单独计数混用

K1-4-3

最大面 / 最小面

★★★

出现明显的最大面或最小面时，看它的形状、边数、对称性、曲直、面积占比、相对位置。

识别信号

  • 图形被一条斜线分成一大一小
  • 存在明显的主面

解题步骤

  1. 先定位最大面/最小面
  2. 按「边数 → 对称 → 曲直 → 与外框相似 → 面积占比 → 位置」顺序逐项试
  3. 两项都无规律 → 试「最大面与最小面形状相同」

判分规则 / 结论

  • 原稿六看：曲直、形状、对称、面积占比、位置关系、与外框相似

易错与反模式

  • 把「最大面」与「外框」混淆

相同面 / 相似面 / 圆内面 / 对称面

★★

识别信号

  • 面数对不上但图形中反复出现同一形状
  • 中部有共同圆、圆内分割越来越多
  • 面内有明显对称形状

解题步骤

  1. 相同面：数「成对相同」的面对数
  2. 相似面：看内面与外轮廓是否相似、是否有平行边
  3. 圆内面：只数圆内部被分割出的面
  4. 对称面：数轴对称面的个数

判分规则 / 结论

  • 圆内面、对称面属较新考点，遇到「圆+分割」优先试

  • 把「相同面」数成「总面数」

第二部分 · 定义判断

定义判断考的是「陌生概念的现场理解与迁移」，不是关键词连连看。做题分三层：先用被定义词定范畴，再拆选项看本质，最后查主体、对象、方式、目的这些硬性限定。

一、总纲：定义判断到底考什么

技巧只是兜底；能不能读懂抽象定义、把它落到具体案例上，才是分水岭。

K2-1-1

★★★

识别信号

  • 题干为专业书面术语（心理效应、管理模式、社会行为）
  • 选项是生活化场景

  1. 先读懂定义在讲哪一类现象
  2. 用生活化例子自测：能不能举出一个符合的例子
  3. 带着这个「例子原型」去比对选项

判分规则 / 结论

  • 对应布鲁姆认知层级：记忆→理解→应用（迁移）

易错与反模式

  • 把定义判断当同义替换、找词游戏

三、题型分类：多定义、具体型、抽象型

题型不同，读法不同：多定义先看设问，具体型抓被定义词，抽象型抓关系。

K2-3-1

★★★

  • 题干分条列出多个定义（时期数列/时点数列）
  • 设问指定其中一个

  1. 先读设问，锁定目标定义
  2. 把目标定义的「区别点」单独标出（如「能否相加」）
  3. 用区别点筛选项，不必读完所有定义

判分规则 / 结论

  • 多定义的关键是「差异点」，不是每个定义的全文

易错与反模式

  • 从头读到尾，读完忘了问的是哪个

  • 定义句很长

解题步骤

  1. 拆被定义词：偏（修饰）+ 正（中心），两者都不能丢
  2. 用中心语定范畴（遗忘/交通/调查）
  3. 用修饰语定特殊限定（动机性/可持续/社会）

判分规则 / 结论

  • 只看「偏」会漏掉中心语，只看「正」会漏掉限定

易错与反模式

  • 把修饰语当全部，忽略中心语的范围

对应题目

答案/解析：脑震荡/阿尔兹海默属病理性遗忘；「不愿回忆」不等于真遗忘；火灾幸存者忘记此事 → 选该项。

五、易错与排除技巧

定义判断的失分，多半不是不懂，而是被「像」的选项骗了。

K2-5-1

机械对标（连连看）的陷阱

★★★

干扰项会刻意对应题干的零散关键词，但动机、结果、场景、核心逻辑完全背离。

识别信号

  • 选项与题干有大量相同词汇
  • 读起来「很像」但说不上哪里不对

解题步骤

  1. 先问「这个选项的行为动机是什么」
  2. 再问「结果是否与定义一致」
  3. 最后才对比字面关键词

判分规则 / 结论

  • 字面重合度高 ≠ 符合定义；重合度越高越要警惕

易错与反模式

  • 看到关键词命中就选

★★

  • 四个选项里三个套路相同
  • 不属于题

解题步骤

  1. 先找出同构的一组
  2. 同构项通常同对或同错
  3. 用剩余选项与定义内核比对

判分规则 / 结论

  • 同构选项一起排除，是「不属于」题最快的解法

  • 逐个死磕，忽略选项之间的结构关系

第三部分 · 类比推理

类比推理只有三层关系：语义、语法、逻辑；再往下是「对应关系」的细分。做题顺序固定：先造句，再定关系，最后纵向对比做二级辨析。

一、语义关系：词本身是什么意思

先看两词是不是同义、反义、引申、象征；成语要拆字看内部结构。

K3-1-1

近义与反义（含褒贬二级辨析）

★★★

两词意思相近或相反；当多个选项都构成近义/反义时，用感情色彩（褒/贬/中）、程度、范围做二级辨析。

识别信号

  • 两词意思明显接近或对立
  • 选项中出现多组近义/反义

解题步骤

  1. 先判断近义还是反义
  2. 多选项同构 → 看褒贬（如「表扬∶恭维」贬义在后）
  3. 仍同构 → 看程度轻重、词义范围

判分规则 / 结论

  • 近义不一定同褒贬，褒贬不一致往往是破题点

易错与反模式

  • 只判断「意思差不多」就选，忽略色彩
  • 把程度词（激动/激烈）当近义

对应题目

Q067近义与反义（含褒贬二级辨析）E-02 原页

答案/解析：近义且后者贬义；应选「表扬∶恭维」（同为近义且后者贬义）。

关联： 成语内部结构

K3-1-2

成语：内部结构与拆字

★★★

成语先辨整体词义（近义/反义），再看内部：「舍本∶逐末」是 1-2 字、3-4 字各成反义。

识别信号

  • 题干与选项都是四字成语
  • 成语可拆成两个二字短语

解题步骤

  1. 整体看近义/反义
  2. 整体同构 → 拆字看内部（反义/近义/并列）
  3. 再看词性（动词/形容词）

判分规则 / 结论

  • 「舍本逐末」：舍与逐、本与末，内部反义

易错与反模式

  • 只比整体意思，不看内部结构

对应题目

关联： 近义/反义

K3-1-3

引申义与象征义

★★★

词的本义之外，用其比喻、指代或象征意义；题干常一词本义、另一词引申义。

识别信号

  • 词有典故、代称（旌旗、孤帆、桃李、巾帼）
  • 两词一实一虚

解题步骤

  1. 先确认哪一个是本义、哪一个是引申义
  2. 延伸方向要一致（都是「物→人」或都是「物→事」）
  3. 二级辨析可看本义类别（衣物/植物/动物）

判分规则 / 结论

  • 「旌旗」指代军队、「孤帆」指代船只，均为以物代人/物

易错与反模式

  • 把比喻义当本义
  • 忽略引申方向（人→物 与 物→人 不同）

对应题目

K3-1-4

同字不同义（本义 / 比喻义）

★★

同一个字在两个词中分别是本义与比喻义；顺序（本义在前还是比喻义在前）也是考点。

识别信号

  • 三词共享一个字（火∶火急∶火警）
  • 词中含该字的两种用法

解题步骤

  1. 标出每个词中该字是本义还是比喻义
  2. 比对顺序（本义+比喻义 / 比喻义+本义）
  3. 再看词性是否一致

判分规则 / 结论

  • 「峰∶山峰∶碳达峰」＝本义+比喻义

易错与反模式

  • 只看字面相同，不看义项

对应题目

K3-1-5

词性辨析（名 / 动 / 形）

★★★

两词语法性质是否一致；拆字后词性也要一致（手足→手、足为名词）。

识别信号

  • 多个选项语义关系都对
  • 词可拆成两个字分别看

解题步骤

  1. 先判整体词性
  2. 再判拆开后各字的词性
  3. 词性不符直接排除

判分规则 / 结论

  • 「左顾∶右盼」：顾、盼为动词；「天昏∶地暗」昏、暗为形容词，故排除后者

易错与反模式

  • 语义对了就不看词性

二、语法关系：词在句中充当什么成分

两词或三词能组成一个短语/句子时，看主谓、动宾、偏正。

K3-2-1

主谓 / 主谓宾

★★★

前者是主体、后者是动作或陈述；三词时可能是「主语 + 宾语 + 谓语」。

识别信号

  • 两词可组成主谓句
  • 三词可连成一句完整的话

解题步骤

  1. 造一个包含所有词的句子
  2. 标出主、谓、宾
  3. 三词题还要比褒贬

判分规则 / 结论

  • 「学生∶知识∶死记硬背」＝主+宾+谓，且含贬义

易错与反模式

  • 把动宾当主谓
  • 忽略三词题的褒贬一致

对应题目

Q074主谓 / 主谓宾E-08 原页

学生∶知识∶死记硬背

答案/解析：主+宾+谓且为贬义；应选「农民∶庄稼∶揠苗助长」。

关联： 偏正

K3-2-2

偏正结构

★★★

前词修饰后词（定中/状中）；比喻式偏正（人潮、夜幕）是高频变体。

识别信号

  • 前词是修饰语（形容词/名词作定语）
  • 后词是中心语

解题步骤

  1. 把前词加「的」看能否修饰后词
  2. 区分动宾（后词是对象）与偏正（后词是中心）
  3. 比喻式偏正：两词都是「像…一样的…」

判分规则 / 结论

  • 「明眸∶善睐」＝偏正 + 特点；「人潮∶夜幕」＝两个比喻式偏正并列

易错与反模式

  • 把偏正当主谓（础润/知雨）
  • 忽略比喻式偏正

对应题目

Q075偏正结构E-09 原页

明眸∶善睐

答案/解析：明眸是偏正，善睐是其特征；应选「老马∶识途」。

Q076偏正结构E-10 原页

人潮∶夜幕

答案/解析：两个比喻式偏正并列；应选「浪花∶火海」。

关联： 主谓宾

K3-2-3

动宾与并列短语

★★

前词是动作、后词是对象（动宾）；两词地位对等则为并列。

识别信号

  • 前词是动词（扬汤、止沸）
  • 两词可互换位置不改变关系

解题步骤

  1. 判断能否加「了」构成动宾
  2. 并列则看词性是否一致
  3. 动宾注意方向（先动作后对象）

判分规则 / 结论

  • 「扬汤∶止沸」是动宾，不是偏正，也不是主谓

易错与反模式

  • 把动宾看成目的关系（扬汤是为了止沸）

对应题目

Q077动宾与并列短语E-09 原页

扬汤∶止沸

答案/解析：动宾结构，且两词有先后动作关系。

关联： 偏正

三、逻辑关系：词与词之间的集合关系

全同、并列、包含、交叉——用集合图判断最快。

K3-3-1

全同关系

★★★

两词指同一对象；细分有音译词、谦称、别称、口语、美称。

识别信号

  • 两词可互换而意思不变
  • 一个是另一个的别称

解题步骤

  1. 先确认全同
  2. 多选项全同 → 看命名方式（音译/谦称/美称/口语）

判分规则 / 结论

  • 因特网∶国际互联网（音译）；拙荆∶妻子（谦称）；瑶琴∶古琴（美称）

易错与反模式

  • 把包含当全同（分母 vs 除数 是全同，内角 vs 外角 不是）

对应题目

Q078全同关系E-13 原页

分母∶除数

答案/解析：数学上全同；应选「百分比∶百分率」。

Q079全同关系E-14 原页

因特网∶国际互联网

答案/解析：全同且为音译词；应选「巴士∶公共汽车」。

关联： 并列关系

K3-3-2

并列关系（矛盾 / 反对）

★★★

同一层级下互不包含：非此即彼为矛盾（生∶死），还有第三方为反对（黑∶白）。

识别信号

  • 两词同类同层
  • 选项中有矛盾与反对两种

解题步骤

  1. 先确认同层并列
  2. 判断是否穷尽（有第三种可能 → 反对）
  3. 三词题看是否为「两种标准」的并列

判分规则 / 结论

  • 匿名投票∶实名投票 是矛盾；早间会议∶午间会议 是反对

易错与反模式

  • 把反对当矛盾
  • 把交叉当并列

对应题目

Q080并列关系（矛盾 / 反对）E-27 原页

匿名投票∶实名投票∶现场投票

第四部分 · 逻辑判断（上）：逻辑论证

削弱、加强、前提、解释四类问法共用一套「论证结构」分析：先找论据与结论，再判断缺口在哪。本部分按缺口类型分化考点，而不是按问法罗列。

一、归因论证

题干给出一组事实并解释其原因。考的是「原因判断是否站得住」，核心武器是另有他因、因果倒置、否定此因。

K4-1-1

对比实验归因 · 另有他因

★★★

题干用「实验组 vs 对照组」的差异结果，推出某一原因导致该结果；削弱时指出两组之间还存在另一个可能影响结果的不同点。

识别信号

  • 题干出现完整实验过程：分组、处理、结果、结论或建议
  • 问法多为「以下哪项如果为真，最能削弱上述结论」
  • 少数问「最能质疑研究人员的解释」，此时抓住「解释」即可，更简单

解题步骤

  1. 圈出实验组与对照组，确认「分组是按什么分的」
  2. 找出结论认定的原因，以及结果指标
  3. 在选项中找「另一处两组不同」——必须落在同一实验分组上
  4. 若题干有多种分组方式，按最终结论反推正确分组，再找该分组下的他因

判分规则 / 结论

  • 正确项必须同时满足：讨论原因 + 分组正确
  • 「继发关联」型他因：A 与 B 无因果，二者同由 C 导致（A←C→B），也属于另有他因

易错与反模式

  • 未谈原因的选项（只谈结果、只谈现象）
  • 未分组的「伪他因」：与实验分组无关的第三方差异
  • 「有些」「特例」类选项，正确概率极低
  • 实验瑕疵类（样本不足、未全覆盖）：质疑力度很弱，通常不是答案

对应题目

答案/解析：该讲师还有暴饮暴食的习惯——引入饮食这一他因，切断「不运动→胖」的归因（若「一果多因」，说明不能唯一归因于不运动）。

K4-1-2

因果倒置

★★★

把原因与结果互相颠倒：题干认为 A 导致 B，削弱时指出实际是 B 导致 A。

识别信号

  • 题干是「相对确定」的因果陈述，而非实验分组
  • 结论句式：「A 会/能导致 B」「A 是 B 的原因」

解题步骤

  1. 把题干写成 A→B
  2. 在选项中找「B→A」的表述
  3. 确认时间或逻辑上的先后能否成立（倒置必须讲得通）

判分规则 / 结论

  • 质疑力度：否定此因 = 因果倒置 > 另有他因
  • 因果倒置一旦成立，直接否定题干的因果方向，力度最强档

易错与反模式

  • 把「相关」当「因果」：只说 A、B 同时出现，不构成倒置
  • 倒置方向写反（说成 A→B 的加强）

★★

  • 题干因果较简单，没有实验分组
  • 选项出现「并不是 A 导致的」「A 与此无关」

解题步骤

  1. 锁定题干认定的原因 A
  2. 在选项中找直接否认 A 的表述

判分规则 / 结论

  • 力度与因果倒置同级，强于另有他因

  • 把「另有他因」误判为否定此因（两者可同时成立，但只有一项在选项里）

识别信号

  • 问法为「最能支持/加强上述结论」
  • 题干为因果归因，选项在「排除干扰因素」

解题步骤

  1. 找出结论认定的原因
  2. 在选项中找「其他原因都不成立/都被控制」的表述
  3. 确认排除的是「可能影响结果的原因」，而不是无关因素

判分规则 / 结论

  • 排除他因 = 归因类加强的标准姿势；与「另有他因」互为镜像

易错与反模式

  • 排除的是无关变量（如天气、地点），对结论无影响

对应题目

题干：某地居民幸福感高，因当地空气好。以下哪项最能支持？

答案/解析：该地居民收入、就业、治安等与幸福感相关的因素与全国平均水平相当——排除他因。

关联： 另有他因

K4-1-5

时间对比归因

★★

题干对比「当前」与「以往」的某种变化并归因；削弱时指出当前与过去还有另一处不同，用他因削弱。

识别信号

  • 题干出现「近年来」「与五年前相比」「过去 5 年」等时间对比
  • 结论：某变化是由某原因造成的

解题步骤

  1. 确定「变化的结果」是什么
  2. 找出题干归因的原因
  3. 在选项中找同一时间段内的「另一处变化」

判分规则 / 结论

  • 一直存在且没有变化的事实，不会是某种「变化」的原因——变化只能由变化解释
  • 注意选项中与题干相同的时间表述（两年前、过去 5 年、1990 年等）

易错与反模式

  • 用恒定因素解释变化（时间错位）

对应题目

Q104时间对比归因C-01 原页

题干：近五年该市近视率上升，因学生课业负担加重。以下哪项最能削弱？

答案/解析：近五年该市中小学生手机使用时长增加了两倍——同一时间段的另一处变化。

关联： 一般归因

K4-1-6

一般归因

★

没有明显对比实验、也没有时间对比，只针对某个既成事实归因；本质仍是「某种情况与其他情况的对比」。

识别信号

  • 题干陈述一个事实并给出解释
  • 无实验组、无时间线

解题步骤

  1. 把「事实」与「默认对照情形」区分开
  2. 按另有他因/否定此因/因果倒置三条路逐一验证选项

判分规则 / 结论

  • 可视为对比实验的弱化版，套路相同

易错与反模式

  • 把一般归因误当对比实验，去找不存在的分组

对应题目

K4-1-7

直接根本原因（固定题型）

★★

题干由「原观点」与「反对者观点」组成，多问「质疑反对者」；答案是「原观点认为的原因」导致了「反对者认为的原因」。

识别信号

  • 两个观点对峙
  • 问法：质疑反对者/支持原观点

解题步骤

  1. 标出原观点原因 A、反对者原因 B
  2. 找「A 导致 B」的选项，即 A 是 B 的根本原因
  3. 确认因果链方向：原观点原因在前

判分规则 / 结论

  • 该题型可秒杀：正确项几乎固定为「A→B」的搭桥表述

易错与反模式

  • 选择「B→A」的倒置项
  • 选择仅重复原观点的选项

对应题目

Q106直接根本原因（固定题型）C-01 原页

原观点：甲导致丙；反对者：乙才是丙的原因。问质疑反对者。

答案/解析：甲导致了乙——原观点原因导致反对者原因，直接拆掉反对者的独立性。

关联： 断点搭桥

K4-1-8

构成或补充对比实验（四圈支持 / 三圈质疑）

★★★

选项本身构成一个对比实验：与题干互为实验组/对照组，通过「异因异果」支持，通过「异因同果」或「同因异果」质疑。

识别信号

  • 题干已有实验，选项再造一组对照
  • 选项出现「另一组人中……」

解题步骤

  1. 画两圈：题干组、选项组
  2. 比较「原因是否相同」与「结果是否相同」
  3. 异因异果 → 支持（四圈支持）；异因同果、同因异果 → 质疑（三圈质疑）

判分规则 / 结论

  • 四圈支持：两因不同、两果不同，因果对应成立
  • 三圈质疑：因不同而果相同，或因相同而果不同，说明因果不成立

易错与反模式

  • 只看结果不看原因，误把「同果」当支持

对应题目

Q107构成或补充对比实验（四圈支持 / 三圈质疑）C-01 原页

题干：服用 X 的人更少感冒，故 X 能防感冒。选项：服用安慰剂的人感冒率与服药组相同。

答案/解析：同果异因——属三圈质疑，说明 X 并非原因。

关联： 另有他因

二、一般质疑

不针对归因，而是针对「论据—结论」之间的推理缺口：论据本身有错、论据不足、论据与结论断链、结论无中生有。

K4-2-1

无论据有结论

★

题干由背景、分析、结论组成而没有硬论据；质疑方式是提出反向论据。

识别信号

  • 题干没有数据、实验、调查，只有道理和判断

解题步骤

  1. 确认题干确实没有事实论据
  2. 构造与结论相反的事实或反例
  3. 核对话题一致、主体正确、贴合题干

判分规则 / 结论

  • 反向论据必须落在同一话题、同一主体上

易错与反模式

  • 答非所问（换了主体或范围）
  • 只表达态度不给论据

对应题目

Q108无论据有结论C-02 原页

题干：本市应全面禁摩，因为摩托车影响市容。以下哪项最能质疑？

答案/解析：本市摩托车事故率与拥堵贡献率均低于私家车，且是部分低收入群体的通勤工具——反向论据。

关联： 有论据有结论

K4-2-2

有论据有结论（四种拆法）

★★★

题干有论据也有结论；按缺口分四类：质疑论据、增加反向论据、断点拆桥、结论无中生有。

识别信号

  • 题干含调查/数据/研究结论
  • 结论往往比论据更进一步

解题步骤

  1. 先判断论据本身是否可靠（个人观点、样本问题 → 质疑论据）
  2. 再看论据是否只覆盖有利面（考虑不全面）或以少数推全部（以偏概全）→ 增加反向论据
  3. 若论据与结论概念不衔接 → 拆桥
  4. 若结论出现论据没有的新内容且程度较重 → 质疑「无中生有」

判分规则 / 结论

  • 对比实验归因可视为特殊的「质疑论据」
  • 拆桥优先于举例：拆桥直接断推理，举例只是弱支持/弱削弱

易错与反模式

  • 拿「另有他因」硬套非因果题
  • 把「重复论据」当加强

对应题目

题干：某调查显示 80% 的用户满意，故产品体验优秀。以下哪项最能质疑？

Q110有论据有结论（四种拆法）C-02 原页

题干：某地引进人才后 GDP 增速提高，故人才政策见效。

答案/解析：同期该地获得大额基建投资——增加反向论据（考虑不全面）。

关联： 严谨逻辑关系质疑

K4-2-3

严谨逻辑关系质疑（A 且非 B）

★★★

结论含逻辑关联词，可翻译为 A→B；削弱即找「A 且非 B」，少数题可用「A→非 B」替代。

识别信号

  • 结论出现「如果…就」「只有…才」「所有…都」
  • 问法为质疑/削弱

解题步骤

  1. 把结论翻译为 A→B
  2. 在选项中找 A 成立而 B 不成立的实例
  3. 核对 A、B 是否为题干原概念（偷换即错）

判分规则 / 结论

  • A→B 为假，当且仅当 A 真且 B 假（前件真、后件假）

易错与反模式

  • 用「非 A 且 B」冒充（这是后件真，命题仍真）
  • 把充分必要方向译反

对应题目

结论：只要加强监管就能杜绝造假。以下哪项最能质疑？

答案/解析：某地监管力度全国最强，造假案件却同比增长——A 且非 B。

关联： 假言命题

K4-2-4

比例类论证

★★

题干用「分子的多少」代替「分子/分母的比例」下结论；削弱时补出分母。

识别信号

  • 题干出现绝对数字（人数、件数、金额）
  • 结论为「更危险/更普遍/更高发」

解题步骤

  1. 识别绝对数 → 比例的偷换
  2. 在选项中找带数字的分母（基数）
  3. 比较两组比例而非数量

判分规则 / 结论

  • 比例题常可秒杀：正确项必带分母数据

易错与反模式

  • 选项只重复分子
  • 选项给的是无关年份的分母

关联： 有论据有结论

三、支持 · 前提 · 解释

三类问法共用「补缺口」逻辑：支持是让结论更可信，前提是让结论能成立（没他不行），解释是让现象说得通。

K4-3-1

五种常见支持方式

★★★

解释说明、断点搭桥、增加正向论据、必要条件（反向代入）、举例支持——按力度与适用场景排序使用。

识别信号

  • 问法：最能加强/支持上述论证、上述发现

解题步骤

  1. 先看结论有没有论据中没有的「新内容」——有则优先找搭桥
  2. 论据有漏洞 → 补漏洞（增加正向论据）
  3. 结论是因果/机制 → 找解释说明
  4. 问「需要前提/假设」→ 用反向代入验必要条件

判分规则 / 结论

  • 断点搭桥：结论新内容必须在选项中出现，并与论据关键信息连接
  • 必要条件：反向代入后结论不成立，才是「没他不行」
  • 举例支持力度弱于搭桥与正向论据；类比支持基本不是答案

易错与反模式

  • 把「有他更好」当成「没他不行」
  • 选项重复题干论据（无增量）
  • 举例支持与类比支持混淆（类比是多对象相似，力度最弱）

对应题目

三种前提假设

★★★

识别信号

  • 问法：需要补充的前提是、还需隐含哪项假设

解题步骤

  1. 找结论中论据没有的新概念 → 搭桥
  2. 找论证缺的那块事实 → 补漏洞
  3. 涉及「能否做到/是否存在」→ 必要条件（能与不能）

  • 搭桥项往往看似「废话」，但把新概念接回论据
  • 补充漏洞常表现为排除某种反向可能（如「不是 B 导致 A」）

易错与反模式

  • 选了加强项但不是必要项（有他更好 ≠ 没他不行）

★★

第五部分 · 逻辑判断（下）：逻辑推理

从「翻译」到「推出」再到「分析」：先把自然语言翻成符号，再用传递、逆否、矛盾、假设去解题。这一部分是纯规则题，练的是准确率与速度。

四、逻辑基础：命题与翻译

五个符号、四种关系、五种关联词——所有推出类题目的地基。

K5-1-1

假言命题与五种关联词

★★★

如果…那么（前推后）、只有…才（后推前）、除非…否则（否 A 推 B）、或者…或者（否一推一）、要么…要么（一真一假）。

识别信号

  • 题干出现关联词
  • 问法：可以推出/不能推出

解题步骤

  1. 圈出关联词，按「前推后/后推前」写出箭头
  2. 「只有 A 才 B」记作 B→A，也可记「不 A 不 B」
  3. 「除非 A 否则 B」记作 非 A→B
  4. 多个命题先别急着联立，先看选项需要哪一句

判分规则 / 结论

  • A→B 等价于 非 B→非 A（逆否），等价于 非 A 或 B（否前或后）
  • 「如果 A 那么 B」的否定是「A 且非 B」
  • 充分条件在箭头前，必要条件在箭头后（谁是必要条件谁放箭头后）

易错与反模式

  • 把必要条件当充分条件（「只有…才」译成 A→B）
  • 「除非…否则」漏掉否定
  • 把「a、b」并列句译成推出关系（它是「且」）

对应题目

Q119假言命题与五种关联词A-17 原页

没有人民支持和参与，任何改革都不可能取得成功；只有充分尊重人民意愿且形成广泛共识，人民才会积极支持改革。可以得出？

答案/解析：只有人民支持和参与，改革才可能取得成功——把「没有…不可能」还原为「成功→支持参与」。

Q120假言命题与五种关联词A-17 原页

「吃得苦中苦，方为人上人。」据此不能推出？

答案/解析：「若能吃得苦中苦，则能成为人上人」——「方」＝「才」，原句是「成为人上人→吃得苦中苦」，该项方向反了。

关联： 命题真假与矛盾 等价推出

K5-1-2

联言命题与选言命题

★★★

且（同时存在，一假则假）与或（至少一个，一真则真）；相容选言「或者」、不相容选言「要么」。

识别信号

  • 「并且、也、还、同时、，」→ 且
  • 「或者、至少一个、至多一个」→ 或

解题步骤

  1. 「A 和 B 至少一个」→ A 或 B
  2. 「A 和 B 至多一个」→ 非 A 或 非 B
  3. 「要么 A 要么 B」→ 一真一假，不能同真同假

判分规则 / 结论

  • 非（A 且 B）＝ 非 A 或 非 B；非（A 或 B）＝ 非 A 且 非 B
  • 「或者」的等价：A 或 B ＝ 非 A→B ＝ 非 B→A（否一推一）
  • 「要么」的矛盾：（A 且 B）或（非 A 且 非 B）

易错与反模式

  • 把「至多一个」译成「A 或 B」
  • 把相容选言当不相容用

对应题目

Q121联言命题与选言命题A-13 原页

「或者去北京，或者去上海」可以推出？

答案/解析：不去北京就去上海——否一推一。

关联： 假言命题

K5-1-3

模态命题与直言命题

★★★

必然/可能、所有/有些的否定与推出关系；记忆口诀「两词互换，后面加不」。

识别信号

  • 「必然、可能、一定、也许」
  • 「所有、有些、有的、特指」

解题步骤

  1. 否定：「所有→有些不」「有些→所有不」「必然→可能不」「可能→必然不」
  2. 推出：所有→特指→有些；必然→可能
  3. 「有些 A 是 B」可推出「有些 B 是 A」，但推不出「有些 A 不是 B」

判分规则 / 结论

  • 上反对（两个所有）必有一假；下反对（两个有些）必有一真
  • 矛盾关系必有一真一假；反对关系可同真或同假

易错与反模式

  • 「有些不」与「有些」当矛盾（实为下反对）
  • 把「有些是」当「有些不是」

对应题目

Q122模态命题与直言命题A-15 原页

「并非所有同学都及格」等价于？

答案/解析：有些同学不及格——「所有…都」的否定是「有些不」。

关联： 命题真假与矛盾

K5-1-4

命题真假与矛盾关系

★★★

A→B 仅在「A 真且 B 假」时为假；矛盾关系三类：性质、或且、推出与且非。

识别信号

  • 问「只有一个为真/为假」
  • 问「与题干真假情况相同」

解题步骤

  1. 先翻译每个命题
  2. 找矛盾对（必一真一假）
  3. 剩余命题按「假设法」或「反对关系」推进

判分规则 / 结论

  • 矛盾关系：A 与非 A；所有与有些不；可能不与必然；A→B 与 A 且非 B；A 且 B 与 非 A 或非 B
  • 前件假则命题真，后件真则命题真（钱建伟 / 侯建真）

易错与反模式

  • 把反对关系当矛盾关系
  • 忘记「前件假命题真」导致误判

对应题目

Q123命题真假与矛盾关系A-19 原页

答案/解析：A 与 8——只有 A 真而 5 假时才推翻；B 前件假、5 后件真，均不足以推翻。

五、推出类：翻译推理

题干给命题，问能推出什么。四条路：等价推出、正推、逆推、两难。

K5-2-1

等价推出

★★★

题干译成 A→B 后，选项等于 A→B 或 非 B→非 A 即为正确；以 B、非 A 开头的选项通常先排除。

识别信号

  • 问法：由此可以推出/不能推出
  • 题干只有一个或少数几个命题

解题步骤

  1. 翻译题干
  2. 逐项翻译选项，保留等价形式
  3. 多项命题时先不联立，看答案只涉及哪一句

判分规则 / 结论

  • 等价只有两种写法：原命题、逆否命题（否定前件/肯定后件都不等价）

易错与反模式

  • 「肯前必肯后，否后必否前；否前肯后不必然」记反

对应题目

Q124等价推出A-17 原页

「只有尊重人民意愿，人民才会支持改革」可以推出？

答案/解析：若人民支持改革，则尊重了人民意愿——后推前的逆否。

关联： 正推与逆推

K5-2-2

正推与逆推

★★

正推：由已知事实沿箭头方向传递；逆推：由目标结果反推所需条件（常考「或」的否一推一）。

识别信号

  • 题干给「已知某人/某事成立」
  • 问「哪项为真可推出 X」

解题步骤

  1. 正推：把事实代入命题链，逐步得结论
  2. 逆推：目标写在箭头后，倒推前件；遇「或」用否一推一

判分规则 / 结论

  • A→B、B→C 可联立得 A→C；A→B、C→B 不可联立

易错与反模式

  • 把「或」当「且」逆推
  • 联立方向搞反

对应题目

Q125正推与逆推A-17 原页

吴教语文→张不教生物；孙教语文或吴教语文；张不教生物→苏不教物理；吴不教化学或苏教物理。哪项为真可推出孙教语文？

答案/解析：吴老师教化学——逆推链：孙语文→吴非语文→张生物→苏物理→吴化学。

关联： 等价推出

K5-2-3

两难推理

★★

A→B 且 非 A→B，则 B 恒成立；A→B 且 A→非 B，则非 A 恒成立。

识别信号

  • 题干两条命题前件互补、后件相同（或相反）

解题步骤

  1. 识别前件是否为 A 与 非 A
  2. 确认后件相同 → 后件必真；后件相反 → 前件必假

判分规则 / 结论

  • 两难的本质是穷尽前件的两种可能

易错与反模式

  • 前件不互补时误用

对应题目

Q126两难推理A-18 原页

如果张生不喜欢旅游，则他对驾车也不感兴趣。据此可推出？

答案/解析：张生喜欢旅游——「非旅游→非驾车」逆否得「驾车→旅游」，两种情形都指向旅游。

关联： 等价推出

K5-2-4

范畴推理（三段论 / 集合关系）

★★★

按「所有/有些/特指」的关系推理；复杂题用文氏图画集合，先分两边再画圈。

识别信号

  • 题干多个「所有/有些」
  • 问「一定为真/一定为假」

解题步骤

  1. 先用最大集合（如 B）把整体分为 B / 非 B 两边
  2. 把「所有 A 都是 B」画进 B 一侧，「所有 C 都不是 B」画到另一侧
  3. 「有些」画成与相关圈相交，注意相交位置不唯一

判分规则 / 结论

  • 三段论技巧：所有+有些=有些；是+是=是、是+否=否；三个概念各出现两次
  • 「有些 A 是 B」推不出「有些 A 不是 B」；未限定条件的概念不能确定位置

易错与反模式

  • 把「有些」画死在某个区域
  • 忽略「所有 C 都不是 B」对 C 的强制排除

对应题目

Q127范畴推理（三段论 / 集合关系）A-19 原页

所有法学专业学生都获得法律职业资格证；所有获法律职业资格证者都获教师资格证；有些法学专业学生成为公务员；所有逻辑学专业学生都未获教师资格证。以下一定为假？

关联： 直言命题

K5-2-5

推理方式判断与论证结构相似

★★

演绎（一般→特殊）、归纳（特殊→一般，分完全/不完全）、类比（特殊→特殊）；结构相似题比对「论证骨架」。

识别信号

  • 问「与上述推理方式相同/最为类似」
  • 题干含举例、调查、类推

解题步骤

  1. 先判定题干是演绎、归纳还是类比
  2. 归纳再分完全（穷尽）与不完全（枚举）
  3. 结构相似题抽出骨架（如「有的 A 是 B，C 是 A，所以 C 是 B」），逐项套

判分规则 / 结论

  • 抽样调查推全体 = 不完全归纳；逐一考察全部对象 = 完全归纳
  • 常见错误骨架：A→B 且 C 是 B 推出 C 是 A；A→B 且 C 非 A 推出 C 非 B；分割谬误（整体属性推个体）

易错与反模式

  • 把演绎当归纳（有一般原理在前即为演绎）
  • 把类比当归纳

对应题目

考察 260 名杀人犯外貌后得出「杀人犯具有某共同特征」。以下哪项推理方式相同？

答案/解析：「八月十五云遮月，正月十五雪打灯」——同属不完全归纳（由部分观察推普遍结论）。

六、分析类：真假话与日常推理

没有固定翻译套路，靠矛盾、假设、代入、画表、赋值五种工具推进。

K5-3-1

真假话：矛盾法 · 假设法 · 代入法

★★★

先找矛盾对锁定真假，再用假设推进；无矛盾时用代入排除。

识别信号

  • 题干若干人各说一句话
  • 给出「只有一人为真/为假」

解题步骤

  1. 翻译每句话，标出矛盾对（必一真一假）
  2. 由真假总数推出矛盾对之外命题的真假
  3. 仍不确定时假设某一命题为真，检查是否自洽
  4. 题干信息多且无矛盾 → 直接代入选项排除

判分规则 / 结论

  • 矛盾对必一真一假，是解题的锚点
  • 涉及「有些/所有」时从特例入手
  • 「或者/至少」类命题在假设中通常为真

易错与反模式

  • 把反对关系当矛盾关系
  • 假设后不回代验证

对应题目

Q129真假话：矛盾法 · 假设法 · 代入法A-19 原页

张教练：没人会达标；孙教练：有队员会达标；王教练：省运会冠军或国家队队员可达标。只有一位预测正确。

答案/解析：没有人达标——「所有不」与「特指」是反对关系可同假，唯一为真的是孙教练的「有些」。

K5-3-2

两真两假模型

★★

四个命题两真两假：先找矛盾对，再假设一点，推出其余真假。

识别信号

  • 题干四个断言、明确两真两假

解题步骤

  1. 配对矛盾
  2. 假设某一支为真，推出全组真假分布
  3. 检查是否恰好两真两假

判分规则 / 结论

  • 矛盾对占去一真一假，剩余两命题必一真一假

易错与反模式

  • 假设后不核验总数
  • 忽略「前件假则命题真」

对应题目

Q130两真两假模型A-19 原页

①两人至少一个考上；②甲不必然考上；③乙考上；④并非甲可能没考上。两真两假。

K5-3-3

日常分析：画表 · 画图 · 赋值

★★★

多人多属性匹配用画表；位置与相邻关系用画图（圆桌拉直）；大小比较用赋值。

识别信号

  • 若干人、若干地点/专业/名次
  • 相邻、左右、围坐
  • 纳税多少、分数高低

解题步骤

  1. 从确定信息、最大信息入手
  2. 画表：行是人、列是属性，确定信息先填
  3. 画图：圆桌按顺时针拉成直线，箭头表示相邻
  4. 赋值：给未知量取具体数字，检验选项

判分规则 / 结论

  • 确定信息 > 最大信息 > 假设
  • 一题两问时，第一问的结论可用于第二问

易错与反模式

  • 表格行列建反
  • 赋值时取了特殊值导致误判

对应题目

Q131日常分析：画表 · 画图 · 赋值A-20 原页

5 人分到 3 个小区，每区 1–2 人；南山最少；邓或丁在南山则吴在北苑；孔邓丁有人在东江则北苑只有洪。

K5-3-4

五类特殊模型

★★★

不同角度分类、包含关系、多重身份、数独、冠军模型——识别模型即可套固定解法。

识别信号

  • 分类计数（师范/非师范 × 男/女）
  • 包含关系（哈尔滨人属于北方人）
  • 一人多身份（专业 + 城市 + 学校）
  • 九宫格/4×4 填词
  • 多人预测、只有一人通过

解题步骤

  1. 分类模型：设未知数，列不等式比较两边
  2. 包含模型：先合并同类，再求最少/最多
  3. 多重身份：画二维表，确定信息先填，再找唯一空位
  4. 数独：从唯一候选格突破
  5. 冠军：把每句话改成「或」，被所有人提到的人不是冠军

判分规则 / 结论

  • 包含关系求「最少」时让集合尽量重叠，求「最多」时尽量分离
  • 多重身份中「农业和江苏抱团」这类线索用于锁定唯一空位

易错与反模式

  • 最少/最多方向搞反
  • 多重身份题重复使用同一线索导致矛盾

第六部分 · 数字推理

数字推理不靠灵感，靠固定的判别链：先看项数与外形，再看差距与单调，最后才动笔做差、做商、做和。本部分把 94 页理论与刷题压缩成「判别顺序 + 八类数列 + 试错纪律」。

一、总纲：判别顺序与试错纪律

顺序错了，算得再对也白费。先分类，再试方法，两次不成就换路。

K6-1-1

四步判别链（项数 → 差距 → 外形 → 兜底）

★★★

拿到数列先做四件事：数项数、看相邻差距、看外形（根号/分数/小数/多位数）、都不行再走因式分解、圈三数、看选项。

识别信号

  • 任何数字推理题的第一步
  • 尤其是真题中「看不出规律」的题

解题步骤

  1. 数项数：≥7 项优先想分组（奇偶、两两、三三）
  2. 看差距：差距小做差，差距大（2–3 倍）做商，数字普遍很小做和
  3. 看外形：根号→统一根式；分数→分子分母分列；小数→整数/小数分列；多位数→拆数位
  4. 都不成：因式分解、圈三数找递推、用选项反推

判分规则 / 结论

  • 数列长（≥7 项）→ 想分组；数列短 → 想多级
  • 「空格不在最后一项，就需要去猜，大胆验证」

易错与反模式

  • 一上来就做差，连做四五次仍不换路
  • 忽略外形（分数/根式）直接当整式处理

对应题目

Q133四步判别链（项数 → 差距 → 外形 → 兜底）

1，4，9，16，25，（ ）

答案/解析：外形贴平方数：1²、2²、3²、4²、5² → 6² = 36。

关联： 试错纪律

K6-1-2

试错纪律：两次即停、一次即换

★★

做差两次没有规律就停，做商一次没有规律就停，转做和或分组；每题只保留一条能解释全列的规律。

识别信号

  • 考场时间压力下的取舍
  • 多个方法都「差不多能凑」时

解题步骤

  1. 做差：最多两层，第二层无规律立即转
  2. 做商：只做一次，商不成等差/等比/幂次就转
  3. 得到规律后必须回代验证全部项，含选项

判分规则 / 结论

  • 「差两次即停、商一次即停」
  • 多解时选能解释全部项、且形式最简单的那条

易错与反模式

  • 为了凑规律强行加修正项
  • 用最后一项倒推规律（会过拟合）

对应题目

Q134试错纪律：两次即停、一次即换N1-01 原页

答案/解析：做差得 1、2、4、8、16（等比），下一差 32 → 65。

关联： 四步判别

K6-1-3

基础数列清单（必须背）

★★★

质数列、合数列、平方数、立方数、2 的幂、阶乘、斐波那契，是识别「像什么」的对照表。

识别信号

  • 数字贴近某个幂次或质数
  • 做差后出现 2、3、5、7、11……

解题步骤

  1. 把数列与基础数列对照（±1、±2 内）
  2. 记住平方 1–20、立方 1–11、2 的 1–10 次方
  3. 质数至少背到 50 以内

判分规则 / 结论

  • 平方：1,4,9,16,25,36,49,64,81,100,121,144,169,196,225,256,289,324,361,400

易错与反模式

  • 把 1 当质数
  • 忘记 0 和负数也可能是幂次项

二、多级数列：做差、做商、做和

整式数列的第一反应，占真题近半。核心是「几层、什么形态」。

K6-2-1

做差（含正负交替、二次差）

★★★

相邻两项相减，看差数列是否为等差、等比、质数、平方或周期；一次不成再做第二次。

识别信号

  • 数列单调、差距不大且逐渐变化
  • 数字在 10–100 之间

解题步骤

  1. 一次差：看是否等差/周期
  2. 二次差：看是否等差、常数、质数
  3. 正负交替：差本身正负交替，考虑符号与绝对值分开看

判分规则 / 结论

  • 二次差为常数 → 原数列是二次函数型（aₙ=an²+bn+c）
  • 三次差才出规律 → 立方型，回代时别少加一层

易错与反模式

  • 只做一层就放弃
  • 二次差算出后忘记回推到原数列

对应题目

Q136做差（含正负交替、二次差）N2-11 原页

2，5，11，23，47，（ ）

答案/解析：差 3、6、12、24（等比），下一差 48 → 95。

关联： 做商

K6-2-2

做和（含做和成等比/质数/平方）

★★

相邻两项相加得新数列，新数列常为等比、质数、平方或立方。

识别信号

  • 数字普遍偏小（≤20）
  • 做差做商都无规律

解题步骤

  1. 两两求和
  2. 看和数列的形态（等比/质数/幂次）
  3. 必要时再做一次和

判分规则 / 结论

  • 「先做差，再求和」——差值有规律但接不上时，改用和

易错与反模式

  • 和数列与原数列混用（把和当成下一项）

对应题目

Q137做和（含做和成等比/质数/平方）N1-07 原页

1，2，3，5，8，13，（ ）

答案/解析：典型两项和递推 → 21（本质是递推，不是多级）。

关联： 递推

K6-2-3

做商（倍数、倍数等差）

★★★

相邻两项相除，看商是否等差、等比、幂次或「倍数 ± 常数」。

识别信号

  • 相邻项呈 2 倍、3 倍关系
  • 「差距已经到 2 倍、3 倍时，差距就大了」

解题步骤

  1. 后项除前项（或前除后，看哪个方向有规律）
  2. 商为等差 → 倍数递增
  3. 商含分数 → 化为分数再找规律

判分规则 / 结论

  • 倍数型常写成 aₙ₊₁ = k·aₙ + b，b 为常数或等差

易错与反模式

  • 除不尽就放弃（小数/分数商也可能是规律）

对应题目

Q138做商（倍数、倍数等差）N1-05 原页

1，3，9，27，81，（ ）

答案/解析：商恒为 3 → 243。

关联： 乘积递推

K6-2-4

多级组合：先差后商、差后作商

★★

差数列本身再做商，或商数列再做差；真题中常以「两级不同方法」出现。

识别信号

  • 差数列是倍数关系
  • 商数列是等差

解题步骤

  1. 先做差，得到新数列
  2. 对新数列做商/做差
  3. 回推两层

判分规则 / 结论

  • 多级组合题必须回推两层，漏一层即错项

易错与反模式

  • 回推时把层数搞错

对应题目

Q139多级组合：先差后商、差后作商

1，2，6，24，120，（ ）

答案/解析：做商：2、3、4、5，下一商 6 → 720。

关联： 试错纪律

三、递推数列：圈三数找规律

差、商、和都不成时，看相邻几项之间能否互相推出。

K6-3-1

加减递推（含 a+b=c 型）

★★★

第三项由前两项相加/相减得到，可能带常数或系数。

识别信号

  • 数列增长平缓
  • 出现「前两项之和≈第三项」

解题步骤

  1. 圈出连续三项，验证 a+b=c
  2. 不成再试 a−b、a+b±1
  3. 系数型试 2a+b、a+2b

判分规则 / 结论

  • 「圈三数找规律」——只看相邻三项，不要看全列

易错与反模式

  • 把递推题当多级，做差后仍无规律却没回头试递推

对应题目

Q140加减递推（含 a+b=c 型）N1-09 原页

2，9，11，20，31，（ ）

答案/解析：aₙ₊₂ = aₙ + aₙ₊₁ → 51。

关联： 倍数递推

K6-3-2

倍数递推（×2±1、×3±1）

★★★

后项约为前项的 2–3 倍，再加减一个常数或简单数列。

识别信号

  • 数值快速增长
  • 相邻项比值接近 2 或 3

解题步骤

  1. 试 aₙ₊₁ = 2aₙ ± 1
  2. 不成试 3aₙ ± 1、2aₙ ± n
  3. 验证全部项

判分规则 / 结论

  • 倍数递推的修正项常为 ±1、±2、±n、±2ⁿ

易错与反模式

  • 只验证前两项就下结论

对应题目

Q141倍数递推（×2±1、×3±1）

3，7，15，31，（ ）

答案/解析：倍数递推 aₙ₊₁ = 2aₙ + 1 → 63。

关联： 加减递推

K6-3-3

乘积/相除递推与「两项相乘」

★★

第三项由前两项相乘（或相除）再加修正得到；刷题中常伪装成多级。

识别信号

  • 数字跳跃大
  • 做商后商本身在变

解题步骤

  1. 试 aₙ·aₙ₊₁ ± k
  2. 试 aₙ₊₁/aₙ ± k
  3. 必要时取倒数（做和取倒数型）

判分规则 / 结论

  • 「做和取倒数」：相邻两项之和恰为后一项的倒数

易错与反模式

  • 把乘积递推错当等比

对应题目

Q142乘积/相除递推与「两项相乘」

2，3，6，18，108，（ ）

答案/解析：乘积递推：后项 = 前两项之积 → 18×108 太大，改看 6×18=108，下一项 18×108=1944。

关联： 倍数递推

四、幂次数列：贴表找修正

看到 9、16、25、27、64 这类数，先想「这是几的几次方」。

K6-4-1

基本幂次：平方、立方、2ⁿ

★★★

通项为 n²、n³、2ⁿ、n! 等，或它们的组合；「注意多次方附近的数值」。

识别信号

  • 数字贴近 4,9,16,25,36 / 8,27,64,125
  • 单调且增长加速

解题步骤

  1. 把每项写成幂次
  2. 看底数、指数是否分别成规律
  3. 不成再看修正

判分规则 / 结论

  • 平方数表 1²–20²、立方表 1³–11³ 必须记熟

易错与反模式

  • 只认平方不认立方
  • 忽略 1 和 0 的特殊性

对应题目

Q143基本幂次：平方、立方、2ⁿN1-24 原页

-1，2，6，21，43，（ ）

答案/解析：各项贴近立方：0³−1、1³+1、2³−2、3³−6、4³−21…按修正规律推得 82。

关联： 幂次修正

K6-4-2

幂次修正（n³+1、平方+1 与立方−1 交替）

★★★

每项 = 幂次 ± 一个小的常数或数列，修正项本身可能有规律。

识别信号

  • 差值序列正好是 1、2、3…或 1、4、9…
  • 数字离幂次只差一点

解题步骤

  1. 写出最接近的幂次
  2. 求修正项并找规律
  3. 修正项可为常数、等差、交替

判分规则 / 结论

  • 「平方+1 与立方−1 交替」是常见变体

易错与反模式

  • 修正项只验证一半就定案

对应题目

Q144幂次修正（n³+1、平方+1 与立方−1 交替）

2，5，10，17，26，（ ）

答案/解析：各项 = n² + 1（1²+1、2²+1…）→ 6²+1 = 37。

关联： 基本幂次

K6-4-3

底数/指数同时变化与分数指数

★★

底数成等差、指数成等差，或出现 1/n、n^(-1) 这类负数次方。

识别信号

  • 每项可写成 aᵇ 且 a、b 各自有规律
  • 出现 1/2、1/4、1/8 与整数混排

解题步骤

  1. 统一写成幂形式
  2. 分别看底数列、指数列
  3. 负指数：1/n = n^(-1)

判分规则 / 结论

  • 「1 与 1/n 相邻 → 负数次方」

易错与反模式

  • 把 1/8 只当分数，不写成 2^(-3)

对应题目

Q145底数/指数同时变化与分数指数

1，4，27，256，（ ）

答案/解析：通项 nⁿ：1¹、2²、3³、4⁴ → 5⁵ = 3125。

关联： 幂次修正

五、分数数列：分子分母分列

分数题的四条路：分列、反约分、通分、伪分数。

K6-5-1

分子分母各成列

★★★

把每项的分子、分母分别写成两列，各自找规律（等差、等比、和递推）。

识别信号

  • 一列分数，分子分母都在变

解题步骤

  1. 分列写出分子列、分母列
  2. 各自判断规律
  3. 必要时两列互相递推

判分规则 / 结论

  • 「分子分母互相递推」——分子由上一项分母加减得到

易错与反模式

  • 先通分再看，导致规律被掩盖

对应题目

Q146分子分母各成列N1-15 原页

1/2，2/5，3/10，4/17，（ ）

答案/解析：分子为 1,2,3,4；分母 2,5,10,17 差为 3,5,7 → 分母 26，答案 5/26。

关联： 反约分/通分

K6-5-2

反约分与通分

★★★

反约分：把已约分的分数还原成同向规律；通分：统一分母后再做差。

识别信号

  • 分母参差不齐但接近倍数
  • 选项分母提示了公分母

解题步骤

  1. 先看选项分母，反推通分目标
  2. 通分后分子做差
  3. 或反约分使分子/分母同向

判分规则 / 结论

  • 「选项的分母 → 通分」是刷题高频技巧

易错与反模式

  • 通分后忘记约分回选项

对应题目

Q147反约分与通分

1/2，2/6，3/12，4/20，（ ）

答案/解析：分子 1、2、3、4；分母 n(n+1) = 2、6、12、20 → 5/30 = 1/6。

关联： 分子分母分列

K6-5-3

伪分数：实为多级或递推

★★

分数只是「外形」，实际规律在数值本身：做差、做积、做商。

识别信号

  • 分数值本身成等差/等比
  • 分子分母没有独立规律

解题步骤

  1. 算出每项的数值
  2. 对数值做差/做商/做积
  3. 如做积恒为质数、做差为等比

判分规则 / 结论

  • 「可约分 → 做积为质数」是一种典型伪分数

易错与反模式

  • 死盯分子分母，忽略数值规律

对应题目

Q148伪分数：实为多级或递推

1/2，2/3，3/5，5/8，（ ）

答案/解析：分子分母各自为前两项之和（斐波那契型）→ 8/13。

关联： 试错纪律

六、小数与根式数列

两种「外形特殊」的数列，各有固定拆法。

K6-6-1

小数数列：分列与内部运算

★★

整数部分与小数部分分列；或对同一项内部做加减（和成倍、差成平方）。

识别信号

  • 每项带小数点且位数一致
  • 整数部分递增、小数部分跳动

解题步骤

  1. 整数列、小数列分别找规律
  2. 试整数+小数、整数−小数
  3. 试隔项成倍

判分规则 / 结论

  • 「小数位 = 整数各位数字和/差」也是常见伪装

易错与反模式

  • 把 3.2 当 32 处理

对应题目

Q149小数数列：分列与内部运算N1-20 原页

3.2，5.7，8.5，12.9，17.8，（ ）

答案/解析：整数列做差为 2,3,4,5；小数列另成规律，合并得下一项 75.85 型（见原页）。

关联： 根式数列

K6-6-2

根式数列：统一根式、内外拆分

★★

先统一根指数或统一成 b√x 形式；不成再把根号内外分别成列。

识别信号

  • 出现 √2、³√5、2√3 等
  • 根号内数字递增

解题步骤

  1. 统一根指数（如都化成平方根）
  2. 写成 b√x：b 列与 x 列分别找规律
  3. 带根指数时看 3,5,7,9 的奇数列

判分规则 / 结论

  • 「根号内外之和为平方数」是统一失败后的退路

易错与反模式

  • 不同根指数直接相加

对应题目

Q150根式数列：统一根式、内外拆分

√2，2√3，3√5，4√7，（ ）

答案/解析：系数 1、2、3、4；根号内 2、3、5、7 为质数 → 5√11。

关联： 小数数列

七、分组与机械拆分

项数多、位数多时的两条路：按位置分组，或按数位拆开。

K6-7-1

奇偶分组（交叉数列）

★★★

奇数项、偶数项各自成列，两列各有规律；常与幂次、等差组合。

识别信号

  • 项数 ≥7
  • 相邻项忽大忽小

解题步骤

  1. 拆成奇数列、偶数列
  2. 分别判断规律
  3. 两列规律可不同（一列等差、一列等比）

判分规则 / 结论

  • 「数列长，想分组」

易错与反模式

  • 两列规律搞混，回填位置错

对应题目

Q151奇偶分组（交叉数列）

1，2，3，4，5，8，7，（ ）

答案/解析：奇数列 1、3、5、7；偶数列 2、4、8、16 → 16。

关联： 两两/三三分组

K6-7-2

两两分组、三三分组（组内和/积恒定）

★★★

两两一组看组内和、差、积、倍；三三一组看 a+b=c 或组内递推。

识别信号

  • 项数为偶数且规律不明显
  • 组内数字关系比相邻项更紧

解题步骤

  1. 两两分组，算组内和/积/商
  2. 组和成等差、等比或恒定
  3. 三三分组试 a+b=c

判分规则 / 结论

  • 组内乘积恒定、组和为常数是高频套路

易错与反模式

  • 分组起点错位（从第二项开始分组）

对应题目

Q152两两分组、三三分组（组内和/积恒定）

1，2，3，6，5，10，7，（ ）

答案/解析：两两分组 (1,2)(3,6)(5,10)(7,14)，组内后项是前项 2 倍 → 14。

关联： 奇偶分组

K6-7-3

数位拆分（多位数两截/数位和）

★★★

把多位数拆成前后两段（如 1234 → 12|34）或拆成各位数字，分别成列。

识别信号

  • 出现四五位数
  • 各数位数一致

解题步骤

  1. 统一从中间劈开成两列
  2. 或求各位数字之和/差
  3. 两列各自找规律

判分规则 / 结论

  • 「差 = 前项数位和」「后两位差 = 各位数字和」是常见伪装

易错与反模式

  • 位数不统一却硬拆

对应题目

Q153数位拆分（多位数两截/数位和）

12，23，35，48，（ ）

答案/解析：差为 11、12、13 → 下一差 14，48+14 = 62。

关联： 两两/三三

K6-7-4

因式分解（全合数、提公因数）

★★

每项都能拆成「两个有规律的因子」，如等差×质数、n×(n+1)。

识别信号

  • 数列全是合数
  • 数值跳跃但都能整除某个数

解题步骤

  1. 逐项分解质因数
  2. 把因子排成两列找规律
  3. 提公因数后再看剩余列

判分规则 / 结论

  • 「全合数 → 先因式分解」

易错与反模式

  • 忘记 1 的处理

对应题目

Q154因式分解（全合数、提公因数）

2，6，12，20，30，（ ）

答案/解析：因式分解 n(n+1)：1×2、2×3、3×4… → 6×7 = 42。

关联： 数位拆分

八、图形数阵与应试策略

九宫格、表格、圆形数阵，本质是「行/列/圈内运算」。

K6-8-1

图形数阵（九宫格、表格、圆形）

★★

在九宫格或圆环中找行内、列内或圈内的加减乘除关系，常见「行内求和/求积」「对角相等」。

识别信号

  • 数字排成方阵或圆圈
  • 某行/列数字关系明显

解题步骤

  1. 先试行内求和/差
  2. 再试列内
  3. 最后试对角、外圈、中心与周围

判分规则 / 结论

  • 九宫格优先「每行三数一个算式」

易错与反模式

  • 只看行不看列

对应题目

Q155图形数阵（九宫格、表格、圆形）

九宫格每行三数：第一行 2、3、5；第二行 4、5、9；第三行 6、7、？

答案/解析：每行满足 a + b = c → 6 + 7 = 13。

关联： 试错纪律

K6-8-2

选项反推与蒙题策略

★★

从选项形态反推规律类型：分子统一→反约分；带 .5→1/2 倍递推；根式→内外之和。

识别信号

  • 时间不足或规律卡住
  • 选项差异有特征

解题步骤

  1. 看选项是否同分母、同根号、带小数
  2. 据此反推最可能的规律
  3. 用该规律验证前几项

判分规则 / 结论

  • 「选项 B/D 数值相近 → 用整数部分趋势蒙」

易错与反模式

  • 完全不验证就选

对应题目

Q156选项反推与蒙题策略

1/2，1/3，1/5，1/8，（ ）

答案/解析：分母差为 1、2、3 → 下一分母 12，答案 1/12（选项分母统一时优先反约分对表）。

关联： 四步判别

第七部分 · 数学运算

数学运算考的不是算术，是「建模 + 选路」：先判断这题属于哪类模型，再套该模型的结构公式，最后用速算与选项特征收尾。本部分按十六讲重排为十类模型，每类只讲识别、公式与步骤。

一、计算与方程：把文字变成式子

数量关系的地基：设元、整除、余数、等差与平方数，决定了后面所有题的速度。

K7-1-1

和差倍比与设元（倍数/比例/倍数链）

★★★

按「谁是谁的几倍/几分之几」设未知数：倍数设 x 与 kx，比例设份数，倍数链设最小公倍。

识别信号

  • 题干出现「是…的 3 倍」「占 40%」「甲比乙多」

解题步骤

  1. 找基准量，设为 x
  2. 倍数关系写成 kx，比例关系设成 3 份、5 份
  3. 多个倍数串联时，设最内层为 x，逐层外推
  4. 列等式：总量相同、时间轴相同、盈亏相同

判分规则 / 结论

  • 「倍数链设元」：A=2B、B=3C 时设 C=x，则 B=3x、A=6x，全是整数

易错与反模式

  • 设了分数导致方程难解
  • 忘记总量守恒

对应题目

Q157和差倍比与设元（倍数/比例/倍数链）L01-02 原页

甲乙丙三数，甲是乙的 2 倍，乙是丙的 3 倍，三数之和为 100，求丙。

答案/解析：设丙 = x，则乙 = 3x、甲 = 6x，10x = 100 → x = 10。

关联： 不定方程

K7-1-2

方程法：时间轴、总量相同、调度表

★★★

三类高频列式场景：时间轴（年龄、工期）、总量相同（户均×户数）、调度表（人员/车辆分配）。

识别信号

  • 题干有「几年后」「同时开工」「每户」
  • 多个对象按不同方案分配

解题步骤

  1. 时间轴：设现在为 x，前后年份统一用 x±n 表示
  2. 总量相同：写出两条路径的总量表达式并相等
  3. 调度表：画表，行是对象、列是方案，空格设未知数

判分规则 / 结论

  • 「总量相同」是最稳的等量关系，优先找它

易错与反模式

  • 年龄题忘记「年龄差不变」
  • 调度表行列建反

对应题目

Q158方程法：时间轴、总量相同、调度表

父亲今年 40 岁，儿子 12 岁，几年后父亲年龄是儿子的 2 倍？

答案/解析：设 x 年后：40 + x = 2(12 + x) → x = 16。

关联： 和差倍比

K7-1-3

不定方程四法（奇偶/尾数/倍数/代入）

★★★

未知数多于方程时，用整除性质缩小范围：奇偶性、尾数、倍数、选项代入。

识别信号

  • ax + by = c 型，求整数解
  • 问「至少/最多/可能」

解题步骤

  1. 先看奇偶：两边奇偶必须一致
  2. 再看尾数：系数含 5 或 10 时看末位
  3. 再看倍数：某项是 3 的倍数则另一项也受限
  4. 最后把选项代入验证

判分规则 / 结论

  • 「a±b 同倍」：a、b 都能被 m 整除，则 a±b 也能被 m 整除

易错与反模式

  • 忘记未知数必须是非负整数

对应题目

Q159不定方程四法（奇偶/尾数/倍数/代入）

3x + 5y = 31（x、y 均为正整数），求全部解。

答案/解析：奇偶 + 尾数：y 为偶数且 5y 尾数 0 或 5；y = 2 时 x = 7，y = 5 时 x = 2，共两组。

关联： 整除特性

K7-1-4

整除特性（3/9/2/5/4/25/8/125）

★★★

用分数的分母、倍数关系直接锁定选项：化最简后分母即倍数，末几位判 4/8/25/125。

识别信号

  • 题干出现分数、百分数、比例
  • 问「多少人」「多少件」必须是整数

解题步骤

  1. 把比例化最简，分母即「总数必须是它的倍数」
  2. 看末一位判 2/5，末两位判 4/25，末三位判 8/125
  3. 各位数字和判 3/9

判分规则 / 结论

  • 「占比反推」：占 3/7 → 总数是 7 的倍数，直接筛选项

易错与反模式

  • 忘记先约分，用未化简的分母判断

对应题目

Q160整除特性（3/9/2/5/4/25/8/125）

某班人数占全年级的 3/7，全年级人数可能是多少？

答案/解析：全年级人数必为 7 的倍数（如 140），据此直接筛选项。

关联： 不定方程

K7-1-5

余数三口诀与同余

★★

余同取余、和同加和、差同减差；都不满足时用「最小公倍数 + 余数」构造。

识别信号

  • 「除以 3 余 2，除以 5 余 2」
  • 问「最少有多少」

解题步骤

  1. 余数相同 → 取余数 + k×lcm
  2. 除数与余数的和相同 → 取和 + k×lcm
  3. 除数与余数的差相同 → 取差 + k×lcm

判分规则 / 结论

  • 三口诀：余同取余、和同加和、差同减差

易错与反模式

  • lcm 用错（应取所有除数的最小公倍数）

对应题目

Q161余数三口诀与同余

一个数除以 4 余 1、除以 5 余 1，最小是多少？

答案/解析：余同取余：lcm(4,5) = 20，20 + 1 = 21。

关联： 整除特性

K7-1-6

等差数列：通项、求和、中项秒杀

★★★

aₙ = a₁ + (n−1)d；Sₙ = n(a₁+aₙ)/2；奇数项时 Sₙ = n × 中项。

识别信号

  • 「连续」「每天多 1」「第 n 排」
  • 求和且项数为奇数

解题步骤

  1. 先定 a₁ 与 d
  2. 求和优先用中项公式（奇数项）
  3. 三角形/方阵排列用「层数 × 中项」

判分规则 / 结论

  • S奇 = n × 中项，是最快的秒杀式

易错与反模式

  • 项数数错（含首尾）

对应题目

Q162等差数列：通项、求和、中项秒杀L04-05 原页

某剧院第一排 20 个座位，以后每排比前一排多 2 个，共 15 排，求总座位数。

答案/解析：a₁=20，d=2，a₁₅=48，S=15×(20+48)/2=510。

关联： 平方数

K7-1-7

平方数/立方数速记与年龄平方

★

1²–20²、1³–11³ 必背；常见考法「年龄的平方等于年份」。

识别信号

  • 出现年份 + 年龄
  • 数字接近完全平方

解题步骤

  1. 把年份写成平方数
  2. 反推年龄
  3. 注意 45²=2025 这类近年平方

判分规则 / 结论

  • 45²=2025、44²=1936，是年龄题的常用锚点

易错与反模式

  • 把平方数记混

对应题目

Q163平方数/立方数速记与年龄平方

某人在 2025 年的年龄恰好是 2025 的平方根，他多少岁？

答案/解析：45² = 2025 → 45 岁。

关联： 等差数列

二、工程问题：W = P × t

三类已知条件，三条路：给时间设 LCM、给效率比直接用、多情形列等式。

K7-2-1

给时间 → 设总量为最小公倍数

★★★

已知各人单独完成时间，设工作总量为这些时间的最小公倍数，效率即为整数。

识别信号

  • 「甲 10 天完成，乙 15 天完成」

解题步骤

  1. 求时间的最小公倍数作为 W
  2. 各效率 = W / 时间
  3. 合作时间 = W / 效率和

判分规则 / 结论

  • LCM 法把分数效率变成整数，避免通分

易错与反模式

  • 总量设成 1 后分数运算出错

对应题目

Q164给时间 → 设总量为最小公倍数L02-02 原页

甲单独 12 天、乙单独 18 天完成某工程，两人合作需几天？

答案/解析：设 W=36，则甲 3、乙 2，合作 36/5=7.2 天。

关联： 效率比直给

K7-2-2

给效率比 → 直接设效率

★★★

已知效率之比时，直接设效率为 2、3、5 这类数，总量随算式自然得出。

识别信号

  • 「甲乙效率比为 3∶2」
  • 「甲的效率是乙的 1.5 倍」

解题步骤

  1. 按比例设效率
  2. 由某段工作量反求总量
  3. 再算所求时间

判分规则 / 结论

  • 效率比可直接当实际效率用，只要全程一致

易错与反模式

  • 效率比与时间比搞反（效率比 = 时间比的反比）

对应题目

Q165给效率比 → 直接设效率

甲乙效率比为 3∶2，两人合作 6 天完成，甲单独做需几天？

答案/解析：设甲 3、乙 2，总量 = (3+2)×6 = 30，甲单独 30÷3 = 10 天。

关联： 设 LCM

K7-2-3

多情形列等式（不同完工方式）

★★★

题干给「甲做几天后乙接手」等多种情形时，按「工作量相等」列方程，不必求总量。

识别信号

  • 同一工程有 2–3 种完成方式
  • 出现「中途换人」「提前几天」

解题步骤

  1. 设总工作量为 1 或 LCM
  2. 把每种情形写成「工作量之和 = 总量」
  3. 两式相减消去总量，直接得效率关系

判分规则 / 结论

  • 「不同完工情况按工作量相等列方程」是通法

易错与反模式

  • 每种情形各设一个总量，导致方程无解

对应题目

Q166多情形列等式（不同完工方式）

甲单独 10 天、乙单独 15 天完成某工程；甲做 4 天后由乙接手，乙还需几天？

答案/解析：设总量 30，甲效率 3、乙 2；甲做 12，余 18，18÷2 = 9 天。

关联： 分段施工

K7-2-4

分段施工、中途请假与效率变化

★★

把工期切成几段，每段算工作量再累加；效率变化按 ×(1+r) 处理。

识别信号

  • 「先做几天，再提高效率」「中途休息 n 天」

解题步骤

  1. 画时间轴分段
  2. 每段工作量 = 效率 × 天数
  3. 剩余工作量 ÷ 新效率 = 剩余天数

判分规则 / 结论

  • 效率提高 20% → 新效率 = 1.2 倍；时间相应缩短为 1/1.2

易错与反模式

  • 请假天数忘了从总工期扣除

对应题目

Q167分段施工、中途请假与效率变化

甲计划 12 天完成，效率 3；做 4 天后停工 2 天，之后每天多做 1，问实际共用几天？

答案/解析：总量 36，前 4 天做 12，余 24；新效率 4，需 6 天 → 4 + 2 + 6 = 12 天。

关联： 多情形

三、经济利润：收入 = 成本 + 利润

折扣、分段、分批都只是把收入与成本拆开算；最值回到二次函数。

K7-3-1

基础利润与折扣

★★★

利润 = 售价 − 成本；利润率 = 利润/成本；折扣按标价打折。

识别信号

  • 「进价」「标价」「打八折」「利润率」

解题步骤

  1. 统一用成本或售价作基准
  2. 打几折 = 标价 × 折扣率
  3. 利润率与折扣率不要混用

判分规则 / 结论

  • 「利润率 = 利润/成本」，不是利润/售价

易错与反模式

  • 把「打八折」算成降价 80%

对应题目

Q168基础利润与折扣

某商品进价 80 元，标价 120 元，打八折出售，利润率是多少？

答案/解析：售价 96，利润 16，利润率 = 16/80 = 20%。

关联： 阶梯计费

K7-3-2

阶梯计费、分批销售与多批成本

★★

分段计价按区间累加；分批销售按各批收入相加 = 总成本 + 总利润。

识别信号

  • 「超过部分按…收费」「先卖一半再降价」

解题步骤

  1. 画分段表：区间、单价、数量
  2. 逐段算金额后相加
  3. 分批题分别算收入与成本

判分规则 / 结论

  • 分段题先算「临界点金额」，再算超出部分

易错与反模式

  • 把分段单价套到全部数量上

对应题目

Q169阶梯计费、分批销售与多批成本

水费前 10 吨每吨 2 元，超出部分每吨 3 元；某户用水 15 吨，应缴多少？

答案/解析：10×2 + 5×3 = 35 元。

关联： 二次函数最值

K7-3-3

利润最值：二次函数两根中点

★★★

利润随涨价/降价呈二次函数，最值在两根中点（对称轴）取得。

识别信号

  • 「每涨 1 元少卖 10 件」
  • 问「最大利润」

解题步骤

  1. 设涨/降价 x
  2. 写出利润函数 (a+x)(b−kx)
  3. 取两根中点或配方求顶点

判分规则 / 结论

  • 两根中点 = 对称轴，比配方快

易错与反模式

  • 忘记 x 必须使销量非负

对应题目

Q170利润最值：二次函数两根中点L08-02 原页

某商品进价 40 元，售价 60 元时每天卖 100 件；每降 1 元多卖 10 件，求最大利润。

答案/解析：设降 x 元：利润 =(20−x)(100+10x)，两根为 20 与 −10，中点 x=5 → 最大 2250 元。

关联： 增长率

K7-3-4

增长率、几何增长与混合增长

★★

连续增长用 (1+R)ⁿ；两期混合增长先求基期比再换现期；间隔增长率用 r₁+r₂+r₁r₂。

识别信号

  • 「连续两年增长」「A 比 B 多 20%」
  • 问「年均增长率」

解题步骤

  1. 定基期与现期
  2. 单期：现期 = 基期 ×(1+R)
  3. 多期：现期 = 基期 ×(1+R)ⁿ
  4. 混合：先算各部分基期，再合并

判分规则 / 结论

  • 间隔增长率 = r₁ + r₂ + r₁r₂

易错与反模式

  • 把「增长 20%」当成「是 20%」

对应题目

Q171增长率、几何增长与混合增长

某量连续两年每年增长 10%，两年后是原来的多少倍？

答案/解析：1.1² = 1.21 倍。

关联： 利润最值

四、溶液与十字交叉

一切以「溶质守恒」为根；两部分混合用十字交叉，差值的比就是量的比。

K7-4-1

溶质守恒：混合、蒸发、倒出补满

★★★

溶质总量在混合、蒸发中不变（倒出会带走溶质），据此列等式。

识别信号

  • 「浓度」「加水」「蒸发」「倒出一半再补满」

解题步骤

  1. 写出溶质 = 溶液 × 浓度
  2. 混合：溶质相加、溶液相加
  3. 倒出：按比例带走溶质

判分规则 / 结论

  • 蒸发只减溶剂，溶质不变；倒出补满后浓度按剩余比例算

易错与反模式

  • 把「倒出一半」当成浓度减半

对应题目

Q172溶质守恒：混合、蒸发、倒出补满

100 克 20% 的盐水，加入 100 克水后浓度是多少？

答案/解析：溶质 20 克不变，溶液 200 克 → 10%。

关联： 十字交叉

K7-4-2

十字交叉法

★★★

两部分混合时，浓度差与质量成反比：差值之比 = 两部分的量之比。

识别信号

  • 两种浓度溶液混合
  • 「平均分」「平均增长率」也可用

解题步骤

  1. 写出两部分的「浓度」
  2. 与混合后浓度求差
  3. 差值的比 = 两部分质量的反比

判分规则 / 结论

  • 十字交叉本质是加权平均，差值比对应分母量（质量、人数）

易错与反模式

  • 把差值比直接当质量比（应为反比）

对应题目

Q173十字交叉法L06-04 原页

30% 与 50% 的溶液混合成 42%，求两者质量比。

答案/解析：差值 12∶8 = 3∶2，质量比为其反比 2∶3。

关联： 溶质守恒

五、容斥：人数与人次

先分清「人数」和「人次」，整体套公式，碎片画七区域。

K7-5-1

两集合容斥

★★★

|A∪B| = |A| + |B| − |A∩B|；总数 = 只 A + 只 B + 都 + 都不。

识别信号

  • 「既…又…」「至少参加一项」

解题步骤

  1. 标出 A、B、交集、补集
  2. 套公式
  3. 问「只参加一项」时再减去交集

判分规则 / 结论

  • 「只 A」= |A| − |A∩B|

易错与反模式

  • 把「都不」漏掉

对应题目

Q174两集合容斥

50 人中会英语 30 人、会日语 20 人、两者都会 10 人，两者都不会的有多少人？

答案/解析：至少会一项 = 30 + 20 − 10 = 40，都不会 = 50 − 40 = 10。

关联： 三集合

K7-5-2

三集合容斥（整体公式与七区域）

★★★

|A∪B∪C| = Σ|A| − Σ|A∩B| + |A∩B∩C|；碎片信息用七区域图逐个填。

识别信号

  • 三个集合、条件零散
  • 「只参加一项」「只参加两项」

解题步骤

  1. 先套整体公式求总数
  2. 条件碎片则画七区域
  3. 从最内层（三者都）往外填

判分规则 / 结论

  • 「只两项」= Σ两两交集 − 3×三者都

易错与反模式

  • 七区域重复计数

对应题目

Q175三集合容斥（整体公式与七区域）

100 人中 |A|=50、|B|=40、|C|=30，两两交集各 10，三者都 5，至少参加一项的有多少人？

答案/解析：50+40+30 − (10+10+10) + 5 = 95 人。

★★

七、周期与日期：取余技术

纯周期除以 T，多周期取 lcm，日期就是「天数差 ÷ 7 取余」。

K7-7-1

余数定位（第 n 次 / 第 n 项）

★★★

把序列按周期 T 分组，n ÷ T 的余数决定落在周期内第几个。

识别信号

  • 「每 3 天一次」「第 100 个是什么」

解题步骤

  1. 确定周期 T
  2. 算 n ÷ T 的余数
  3. 余数为 0 时取周期末项

判分规则 / 结论

  • 「第 k 次 ≠ k×T」——起点是否算第 1 次要看清

易错与反模式

  • 把「隔 n 天」当成「每 n 天」（应为 n+1）

对应题目

Q180余数定位（第 n 次 / 第 n 项）

某活动每 4 天一次，第 100 天是循环中的第几天？

K7-7-2

★★★

识别信号

  • 「甲乙丙每隔…同时…」

解题步骤

  1. 列出各周期
  2. 求 lcm
  3. 用总时长 ÷ lcm 得次数

判分规则 / 结论

  • 「同时发生」= 取 lcm；「下一次」= lcm 之后

易错与反模式

  • 直接相乘（未约分）

对应题目

K7-7-3

日期星期推算（粗算 + 修正 + 取余）

★★

识别信号

  • 「某年某月某日是星期几，求另一天」

解题步骤

  1. 粗算相隔天数
  2. 修正：闰年 2 月 +1，大小月差 1
  3. ÷7 取余，余数即星期位移

判分规则 / 结论

  • 闰年判据：能被 4 整除且不能被 100 整除，或能被 400 整除

  • 跨年忘记闰年
  • 把「隔 n 天」与「第 n 天」混淆

K7-7-4

★★

  • 「本月有 5 个星期一」
  • 「相邻两星期各出现 5 次」

  2. 算多余天数（0/1/2/3）
  3. 把多余天数分配给月初/月末

  • 31 天 = 4 周 + 3 天，故有 3 个星期各多出现一次

  • 把「多余 2 天」当成「多 2 个星期」

★★★
